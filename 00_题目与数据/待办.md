## 1. 题意和优化目标

### 1.1 决策变量

设场地中心为 $O=(0,0)$，吸收塔水平坐标为 $T=(x_T,y_T)$。所有定日镜尺寸和安装高度相同，定义：

- 镜面宽度 $w$，镜面高度 $h$；
- 安装高度 $a$，即镜心的 $z$ 坐标；
- 镜面数 $N$；
- 镜面中心坐标 $p_i=(x_i,y_i)$，三维镜心为 $H_i=(x_i,y_i,a)$，$i=1,\ldots,N$。

集热器中心随塔位平移为 $C=(x_T,y_T,80)$。对给定设计，按问题一的 60 个代表时刻计算年平均输出热功率 $\bar P$，单位面积年平均输出热功率为

```text
q = 1000 * P_bar / (N * w * h)       [kW/m^2]
```

题目要求在额定年平均功率 60 MW 下使 `q` 最大。由于额定功率固定，优化可等价写成：

```text
minimize A_total = N * w * h
subject to P_bar >= 60 MW
```

搜索阶段允许 `P_bar >= 60`，最终通过删减低贡献镜面或微调布局将功率压回额定值附近，并报告实际功率、总面积和单位面积功率。不得用“分项平均效率的乘积”代替逐镜综合效率后再求平均。

### 1.2 硬约束

- [ ] 场地约束：`x_i^2 + y_i^2 <= 350^2`。
- [ ] 塔周禁装区：`(x_i-x_T)^2 + (y_i-y_T)^2 >= 100^2`。
- [ ] 镜面尺寸：`2 <= h <= w <= 8` m。
- [ ] 安装高度：`2 <= a <= 6` m，并满足 `a >= h/2`。该条件保证镜面绕水平转轴旋转时最低边不会低于地面。
- [ ] 相邻底座中心距离：`||p_i-p_j|| >= w+5` m。
- [ ] 塔位在场地圆形区域内：`x_T^2 + y_T^2 <= 350^2`；若塔位靠近边界导致可行镜面不足，由布局生成器判为不可行。
- [ ] 太阳时刻、DNI、反射率、集热器尺寸和年平均口径与问题一完全一致。

### 1.3 数值口径

- [ ] 额定功率采用 `P_bar >= 60 MW` 作为可行性约束；最终方案记录功率超额，并以面积最小的可行方案为优先。
- [ ] 若多个方案总面积相同，按年平均功率更接近 60 MW、阴影遮挡效率更高、塔位偏移更小的顺序择优。
- [ ] 月均为每月 5 个时刻等权平均，年均为 12 个月等权平均；不能改为按真实日照时长加权。
- [ ] 长度单位为 m，功率单位为 MW，单位面积功率单位为 kW/m^2。

## 3. 分层求解策略

直接以全部镜面坐标作为连续优化变量的维数约为 `2N+5`（N 为千级），且每次评价还要进行 60 时刻射线追迹，计算量和不可行解比例都不可接受。因此采用三层流程：

```text
外层：塔位、w、h、a、晶格旋转/相位的全局搜索
  ↓
内层：生成满足最小间距的候选镜位，按快速贡献排序并选取最少镜面
  ↓
复核层：对少量候选方案使用问题一同口径的完整 60 时刻射线模型
```

### 3.1 候选布局：六角晶格 + 可行性修复

对固定 `(T,w,h,a)`，取晶格间距 `d=w+5`，在场地坐标系生成三角/六角晶格：

```text
e1 = (d, 0)
e2 = (d/2, sqrt(3)*d/2)
p(i,j) = phase + i*e1 + j*e2
```

外层同时搜索晶格旋转角 `theta` 和一个基本胞内相位 `phase`，再筛选满足场地圆、塔周禁装区的点。六角晶格天然满足相邻间距约束，比逐点随机投放更稳定。

- [ ] `theta` 取 `[0,pi/3)`，相位限制在一个基本胞内，避免等价解重复搜索。
- [ ] 对候选点建立空间哈希，删除距离小于 `w+5` 的冲突点；删除操作按快速贡献从低到高进行。
- [ ] 对塔位附近和场地边界使用显式距离检查，不能只检查晶格索引。
- [ ] 预留局部扰动接口：在最终方案周围对单个镜面做小幅平移，并通过空间哈希修复冲突。

六角晶格是降维和初始化策略，不是题目的额外约束。最终局部优化允许在晶格点附近移动镜面；移动后仍满足全部约束的点才能保留。

### 3.2 快速单镜贡献和效率地图

忽略镜间遮挡时，位置 `p` 的年度单位面积贡献定义为

```text
Phi(p;T,w,h,a) = mean_t[DNI_t * eta_cos(p,t) * eta_at(p;T)
                         * eta_trunc(p,t;T,w,h,a)]
```

`eta_cos` 和 `eta_at` 可解析向量化；`eta_trunc` 采用问题一的太阳光锥-圆柱求交，但优化阶段使用低精度采样和空间插值。

- [ ] 将现有 `efficiency_map.py` 改为相对塔位坐标 `p-T` 的参数化地图，不得继续假定塔位为原点。
- [ ] 建立低精度地图：位置网格步长约 10--15 m，镜面采样 `6x6`，光锥光线数取基准的 `1/4--1/8`；仅用于排序和外层适应度。
- [ ] 地图按 `(tower_xy,width,height,install_height)` 缓存；同一外层个体及其局部邻域复用缓存，避免重复追迹。
- [ ] 先做一次尺寸/安装高度敏感性试算；若截断效率在允许范围内变化很小，可在外层使用基准尺寸地图，并在复核层恢复真实参数。
- [ ] 地图插值覆盖塔位偏移后可能出现的相对距离（最远可接近 `700 m`）；实际镜位仍同时检查全局场地圆和塔周禁装区，场外点直接判无效，禁止用外推值生成镜位。

快速无阴影功率估计为：

```text
P_fast = eta_ref * width * height * sum(Phi_i)
```

为避免系统性高估，在排序阶段加入由问题一校准得到的阴影折减因子 `s_shadow`，或用每个候选点的中心光线/邻域镜面快速判定得到 `eta_sb_fast`。该估计只用于筛选，最终功率必须用完整模型重算。

### 3.3 内层选镜：先满足功率，再最小化面积

对每个候选布局：

1. 计算 `score_i = width*height*eta_ref*Phi_i*eta_sb_fast_i`。
2. 按 `score_i` 降序建立镜面序列；六角晶格已满足间距，局部扰动点则用空间哈希逐点检查。
3. 累加快速贡献，直到 `P_fast >= 60 MW`，得到初始镜面数 `N0`。
4. 从序列末端尝试删除镜面，直到删除一面会使功率低于 60 MW；固定宽高时，这近似得到最少镜面数。
5. 对候选方案用低精度完整阴影模型复算；若功率不足，按边际贡献补镜或替换低效镜面。

由于同一设计的单镜面积相同，`N` 越小总面积越小，内层不需要把 `N` 作为独立连续变量搜索；离散调整由增删/替换操作完成。

### 3.4 外层全局搜索和局部改进

外层变量建议为：

```text
(x_T, y_T, width, height, install_height, theta, phase_x, phase_y)
```

采用差分进化（DE）或粒子群（PSO）做全局搜索，种群规模控制在 24--48，迭代 30--60 代；每个个体只调用快速地图和内层选镜，不调用高精度完整追迹。适应度采用带功率缺口惩罚的面积目标：

```text
F = A_total + lambda * max(0, 60 - P_fast)^2
```

`lambda` 取使 1 MW 功率缺口远大于一个镜面面积变化的量级，并在每 5--10 代自适应增大。可行个体之间直接比较 `A_total`，避免惩罚项改变可行解排序。

对外层前 `L` 个候选（建议 `L=10--20`）执行局部改进：

- 塔位做 `+/-5 m`、`+/-2 m` 的坐标扰动；
- `width/height/install_height` 做离散步长邻域搜索；
- 晶格相位和旋转角做小幅扰动；
- 单镜执行移位、删除、补镜和一换一替换；
- 每次改动先做约束和快速功率检查，再进入完整评价。

局部搜索接受准则为：先满足功率，再降低总面积；面积相同则提高年平均功率裕量或提高阴影遮挡效率。连续变量最终可用网格细化，不依赖不可解释的超高精度小数。

## 4. 精确评价器和复杂度预算

### 4.1 两级评价精度

| 阶段 | 镜面网格 | 光锥光线 | 阴影/挡光 | 用途 |
|---|---:|---:|---|---|
| 外层快速评价 | `6x6` | 基准的 `1/4--1/8` | 中心点或低精度采样 | DE/PSO 适应度 |
| 候选复筛 | `8x8` | 约 `512` | 全有效采样点 + 空间邻域 | 排名前 10--20 |
| 最终报告 | 问题一基准 `10x10` | `1024` | 完整 60 时刻 | 结果和表格 |

所有阶段使用同一太阳方向、圆柱求交和约束定义；只改变采样精度，不改变物理口径。

### 4.2 复杂度

记代表时刻数 `T=60`，镜面采样点数 `S=g^2`，光锥光线数 `K`，每面平均候选邻居数为 `k`，候选位置数为 `M`：

- 快速地图/单镜贡献：`O(T*M*K*S)`；地图建好后插值查询为每点 `O(T)`。
- 低精度阴影：`O(T*N*S*k)`；空间哈希构造为 `O(N)`，不再构造 `N x N` 距离矩阵。
- 最终完整评价：`O(T*N*(S*k + S*K))`，其中阴影部分为 `S*k` 次矩形求交，截断部分为 `S*K` 次圆柱求交。
- 外层总成本约为 `种群数*代数*快速评价 + L*完整复筛`，而不是 `种群数*代数*N*全场镜面`。

实现中必须记录每次评价耗时、候选镜数、平均邻居数和缓存命中率。若完整复筛超时，优先降低候选数量 `L` 或使用 `8x8/512`；不能删除最终 60 时刻的验算。
