## 六、阴影遮挡效率

根据张平论文[2]，阴影挡光损失包括三部分：
- **① 塔对镜场造成的阴影损失**：沿太阳光线方向 s，计算塔身投影对镜面的遮挡（优先级最高）
- **② 后排定日镜接收的太阳光被前方定日镜所阻挡（阴影损失）**：沿太阳光线方向 s
- **③ 后排定日镜在反射太阳光时被前方定日镜阻挡而未到达吸热器上（挡光损失）**：沿反射光线方向 t

**注意**：
- 塔对镜场只有阴影影响，没有挡光影响
- **计算顺序**：先塔阴影 → 再镜间阴影 → 最后镜间挡光，避免重复扣除

### 6.1 塔阴影计算

**塔参数假设**：
- 塔身形状：圆柱形（与集热器相同）
- 塔身半径：`TOWER_RADIUS = 3.5 m`（与集热器半径相同）
- **塔+集热器合并为完整圆柱**：高度范围 `[0, 84] m`，半径 3.5 m
  - 塔身：`[0, 76] m`
  - 集热器：`[76, 84] m`
  - ⚠️ **集热器同样会遮挡太阳光形成阴影，必须纳入塔阴影计算**
  - 因半径相同、轴线重合（都在塔中心），塔身与集热器可合并为一个连续圆柱，无需分开判定

**塔阴影计算方法**：
- [ ] 塔只有 1 个，无需空间筛选，直接对所有镜面采样点做射线-圆柱求交
- [ ] 对每面镜的每个采样点 P，沿太阳方向 s 反向延长射线（方向 -s）
- [ ] 判断射线是否与圆柱形塔体 `x²+y² = R², z ∈ [0, 84] m` 相交
- [ ] 相交则标记为损失，跳过镜间阴影/挡光判定
- [ ] 低太阳高度角时注意二次方程判别式的数值稳定性

**光线与圆柱交点计算公式**：
```
圆柱方程：x² + y² = R²，z ∈ [0, 84]
光线方程：P + λ·(-s)，其中 P 为镜面采样点，λ > 0

将光线代入圆柱方程（水平分量）：
(Px - λ·sx)² + (Py - λ·sy)² = R²
→ A·λ² + B·λ + C = 0
A = sx² + sy²
B = -2(Px·sx + Py·sy)
C = Px² + Py² - R²

判别式 Δ = B² - 4AC
- Δ < 0：无交点，不被遮挡
- Δ ≥ 0：取最小正根 λ_min，检查 z = Pz - λ_min·sz ∈ [0, 84]
- z 在范围内 → 被塔阴影遮挡
```

### 6.2 阴影遮挡效率综合计算（优先级顺序）

**计算策略**：按优先级顺序判定，避免重复扣除
```
对每个采样点：
1. 先判断塔阴影（优先级最高，圆柱 [0,84]m）
   ├─ 被塔阴影遮挡 → 标记为损失，跳过后续计算
   └─ 未被塔阴影遮挡 → 继续下一步

2. 判断镜间阴影（沿太阳方向 s）
   ├─ 被镜间阴影遮挡 → 标记为损失，跳过挡光计算
   └─ 未被镜间阴影遮挡 → 继续下一步

3. 判断镜间挡光（沿反射方向 r）
   ├─ 被镜间挡光遮挡 → 标记为损失
   └─ 未被遮挡 → 该采样点有效

最终：eta_sb = 有效采样点数 / 总采样点数
```

**镜面坐标系与采样**：
- [ ] 依据镜面法向量 n 构造镜面宽度方向 u 和高度方向 v 的正交单位基
- [ ] **宽度方向 u 必须水平**（题目：上下两条边始终平行于地面）：
  ```
  u = normalize(-ny, nx, 0)，其中 n = (nx, ny, nz)
  即法向在水平面的投影旋转 90°
  ```
- [ ] 高度方向 v = n × u（右手系，正交于 n 和 u）
- [ ] 将每面 `6 m x 6 m` 镜面划分为规则采样网格，初始可采用 `10 x 10` 或 `20 x 20`：
  ```
  采样点 P_ij = C + (i/N - 0.5)·6·u + (j/N - 0.5)·6·v
  ```

**镜间阴影判定**（仅对未被塔阴影遮挡的点）：
- [ ] 沿太阳方向 s 反向发射射线（方向 -s），判断是否先与其他镜面相交
- [ ] 入射方向对镜面上所有点相同（太阳为平行光），可直接用 -s

**镜间挡光判定**（仅对未被遮挡的点）：
- [ ] **沿反射方向 r 发射射线，而非集热器方向 t**
  ```
  反射方向（平面镜，所有采样点相同）：r = 2(s·n)·n - s
  ```
- [ ] 判断反射光线到达集热器前是否与其他镜面相交
- [ ] 注：t 是镜心→集热器中心的单位向量，r 与 t 的偏差约镜面半宽/镜塔距离（≈3/350≈0.9%），可作验证用近似

**候选镜面筛选**（关键性能优化）：
- [ ] 镜间阴影/挡光只需检查空间近邻镜面，无需 O(N²) 全遍历
- [ ] 预计算每面镜的镜心坐标，按空间网格哈希分桶（网格边长约 20 m）
- [ ] 或直接筛选镜心距离 < 阈值（如 30 m）的候选镜
- [ ] 对每个采样点只对候选镜判定，大幅降低计算量
- [ ] 塔阴影只有一个圆柱，无需筛选

**光线与矩形镜面交点计算公式**：
```
设候选镜面中心 C_j，法向量 n_j，宽度方向 u_j，高度方向 v_j
镜面范围：|(Q - C_j)·u_j| ≤ 3，|(Q - C_j)·v_j| ≤ 3

光线方程：P + λ·d，其中 d = -s（阴影）或 d = r（挡光），λ > 0
镜面平面方程：(Q - C_j)·n_j = 0

联立求解交点 Q：
λ = (C_j - P)·n_j / (d·n_j)
- 若 d·n_j ≈ 0：光线平行于镜面，无交点
- 若 λ ≤ 0：交点在反方向，无效
- 若 |(Q - C_j)·u_j| ≤ 3 且 |(Q - C_j)·v_j| ≤ 3：被该镜面遮挡
```

**验证**：
- [ ] 检查低太阳高度角时阴影遮挡损失是否明显增大
- [ ] 收敛测试：10×10 → 20×20 采样网格，检查 eta_sb 是否收敛
- [ ] 抽取若干内圈、外圈镜面，人工检查光线几何是否正确

**光线与矩形镜面交点计算公式**：
```
设镜面中心 C，法向量 n，镜面宽度方向 u，高度方向 v
镜面四角：C ± 3u ± 3v（3m = 镜面半宽）

光线方程：P + λ·d，其中 d = -s 或 d = -t
镜面方程：(r - C) · n = 0

联立求解交点 Q，判断 Q 是否在镜面矩形范围内：
- 投影到 u 方向：|(Q - C) · u| ≤ 3
- 投影到 v 方向：|(Q - C) · v| ≤ 3
- 投影到 n 方向：|(Q - C) · n| < ε（容差）
```

## 七、截断效率

**定义**（题目附录）：ηtrunc = 集热器接收能量 / (镜面全反射能量 − 阴影遮挡损失能量)
- 分母 = 已通过阴影遮挡判定的有效采样点发射的光线总数
- 分子 = 其中到达集热器接收面的光线数
- 与张平论文定义一致：分母除去阴影挡光等损失后的反射能量

**入射光锥坐标系**（张平论文式 9-11）：
- 主光线方向 = 镜面采样点指向太阳 = +s（太阳方向单位向量）
- Z_S 轴沿主光线方向（朝向太阳圆盘中心）
- X_S 轴始终与地面平行：X_S = normalize((−sy, sx, 0))（水平投影旋转 90°）
- Y_S = Z_S × X_S（右手系）
- 任一光线在光锥坐标系：V_S = (sinσ·cosτ, sinσ·sinτ, cosσ)
  - σ ∈ [0, σ_max]：与主光线的夹角，σ_max = 4.65 mrad（太阳半角）
  - τ ∈ [0, 2π)：周向角
- 转换到地面坐标系：V_Sl = X_S·sinσ·cosτ + Y_S·sinσ·sinτ + Z_S·cosσ

**入射方向采样方式**（二选一，推荐 Sobol 准随机）：
- [ ] 方案 A（角均分法，张平论文）：σ 方向 N_σ 等分 + τ 方向 N_τ 等分，确定性网格
- [ ] 方案 B（Sobol 准随机序列）：σ = σ_max·√u1, τ = 2π·u2，u 为 Sobol 序列，结果可复现
- [ ] 固定随机种子或使用 Sobol 序列保证结果可复现

**计算步骤**：
- [ ] 在镜面有效区域内采样光线起点（复用阴影遮挡的采样网格点）
- [ ] 对每个采样点，在光锥内采样若干入射方向（每条入射光线单独计算）
- [ ] 根据镜面法向量计算每条入射光线的反射方向：r = 2(s'·n)·n − s'
  - 其中 s' 是该条入射光线方向（光锥内，非主光线方向）
- [ ] 求反射光线与半径 3.5 m 的圆柱侧面交点：
  ```
  圆柱方程：x² + y² = R², z ∈ [76, 84]
  光线方程：Q = P + λ·r，λ > 0
  → Aλ² + Bλ + C = 0（水平分量），A = rx² + ry²
    B = 2(Px·rx + Py·ry)，C = Px² + Py² − R²
  ```
- [ ] 判断交点高度是否处于 [76, 84] m，并排除射线反方向的无效交点（λ ≤ 0）
- [ ] 排除未通过阴影遮挡判定的采样点（避免与 η_sb 重复计算）
- [ ] 以到达集热器侧面的光线比例计算 ηtrunc
- [ ] 增加太阳视圆采样数，检查截断效率和功率结果是否收敛（记录时间与相对误差）
