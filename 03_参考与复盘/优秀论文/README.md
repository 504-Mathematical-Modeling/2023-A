# 2023 国赛 A 题 · 优秀论文参考资料

本文档整理了 2023 年全国大学生数学建模竞赛 A 题「定日镜场的优化设计」的高质量参考论文，用于赛前练习时的思路借鉴与写作对照。

## 论文清单

| 文件 | 等级/来源 | 页数 | 特点 |
|------|----------|------|------|
| `2023A_定日镜场优化设计_国家一等奖论文.pdf` | 全国一等奖 | 60 | 完整建模流程：几何建模 → 效率计算 → PSO 布局优化，含答辩 PPT 同套仓库 |
| `2023A_基于复合光线追踪_贝叶斯拟梯度优化_送评国一论文.pdf` | 送评国一/国二 | 36 | 方法新颖：复合光线追踪 + 贝叶斯-拟梯度下降布局优化，numpy 张量并行加速 |
| `2023A_基于太阳能光热发电效率的方案分析_应用数学进展期刊论文.pdf` | 期刊论文（公开） | 22 | 卷积积分 + 模拟镜场 + 遗传算法/多维 PSO，分析详尽 |

## 建议阅读顺序

1. 先读**国家一等奖论文**：按标准论文结构走一遍，看摘要六段法、四小节结构如何落地
2. 再读**送评国一论文**：看创新方法如何提炼成"亮点"（光线追踪 + 贝叶斯优化），编程实现细节值得参考
3. 最后读**期刊论文**：偏学术规范，适合对照物理公式（余弦效率、阴影遮挡、截断效率）的推导
