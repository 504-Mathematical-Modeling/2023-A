# 问题一待做清单

## 一、任务目标

- [ ] 读取附件中的全部定日镜坐标，确认定日镜总数为 1745 面。
- [ ] 计算 12 个月 21 日在 9:00、10:30、12:00、13:30、15:00 共 60 个代表时刻的镜场性能。
- [ ] 输出表 1：每月 21 日平均光学效率及输出功率。
- [ ] 输出表 2：年平均光学效率及输出功率。

## 二、固定参数与计算口径

- [ ] 建立镜场坐标系：正东为 x 轴、正北为 y 轴、竖直向上为 z 轴。
- [ ] 固定当地纬度为 39.4 度，海拔为 3 km。
- [ ] 固定吸收塔位置为 `(0, 0)`，集热器中心为 `(0, 0, 80)` m。
- [ ] 固定集热器为半径 3.5 m、高度区间 `[76, 84]` m 的圆柱侧面。
- [ ] 固定定日镜尺寸为 `6 m x 6 m`，安装高度为 4 m，单镜面积为 36 m2。
- [ ] 固定总镜面面积为 `1745 x 36 = 62820 m2`。
- [ ] 固定镜面反射率 `eta_ref = 0.92`。
- [ ] 按题目给出的当地时间直接计算太阳时角，不额外进行北京时间或真太阳时修正。
- [ ] 月平均采用每日 5 个时刻等权平均，年平均采用 12 个月等权平均。
- [ ] 明确太阳锥形光束的半角取值及来源；若采用常用太阳半角，可取约 4.65 mrad。

## 三、数据准备

- [ ] 读取 `附件.xlsx` 的 x、y 坐标，构造镜面中心 `H_i = (x_i, y_i, 4)`。
- [ ] 检查坐标是否存在缺失值、重复值或非数值项。
- [ ] 检查所有镜面中心到原点的水平距离是否处于 100 m 至 350 m 范围内。
- [ ] 检查相邻镜面底座中心距离是否满足题设布局特征。
- [ ] 绘制定日镜位置散点图，确认附件为环形镜场布局。

## 四、太阳位置与 DNI

- [ ] 给出各月 21 日相对春分的天数 `D`。
- [ ] 根据题目公式计算太阳赤纬角 `delta`。
- [ ] 根据五个当地时刻计算太阳时角 `omega`。
- [ ] 计算太阳高度角 `alpha_s`。
- [ ] 直接构造太阳方向单位向量，避免使用 `arccos` 时丢失上午、下午的方位信息：

  ```text
  s_x = -cos(delta) sin(omega)
  s_y = cos(phi) sin(delta) - sin(phi) cos(delta) cos(omega)
  s_z = sin(alpha_s)
  ```

- [ ] 检查太阳向量模长是否为 1，并检查上午 `s_x > 0`、下午 `s_x < 0`。
- [ ] 代入海拔 3 km，预先计算 DNI 参数：

  ```text
  a = 0.34981
  b = 0.5783875
  c = 0.275745
  ```

- [ ] 计算每个代表时刻的法向直接辐射辐照度 DNI。

## 五、定日镜姿态与解析效率

- [ ] 计算每面镜中心指向集热器中心的单位向量：

  ```text
  t_i = (C - H_i) / ||C - H_i||
  ```

- [ ] 根据反射定律计算镜面法向量：

  ```text
  n_i = (s + t_i) / ||s + t_i||
  ```

- [ ] 计算余弦效率：

  ```text
  eta_cos_i = dot(s, n_i)
  ```

- [ ] 计算镜面中心至集热器中心的距离 `d_HR,i`。
- [ ] 根据题目公式计算大气透射率 `eta_at,i`；该量仅与镜面位置有关，可提前缓存。
- [ ] 检查所有效率是否位于 `[0, 1]` 范围内。

## 六、阴影遮挡效率

- [ ] 依据镜面法向量构造镜面宽度方向和高度方向的正交单位基。
- [ ] 将每面 `6 m x 6 m` 镜面划分为规则采样网格，初始可采用 `10 x 10` 或 `20 x 20`。
- [ ] 对每个采样点沿太阳方向发射射线，判断是否先与其他镜面相交，以确定阴影损失。
- [ ] 对每个采样点沿集热器方向发射射线，判断到达集热器前是否与其他镜面相交，以确定遮挡损失。
- [ ] 将阴影区域和遮挡区域取并集，避免重复扣除损失。
- [ ] 计算 `eta_sb = 有效采样点数 / 总采样点数`。
- [ ] 使用空间网格、KD-tree 或邻域筛选减少候选遮挡镜面数量。
- [ ] 检查低太阳高度角时阴影遮挡损失是否明显增大。

## 七、截断效率

- [ ] 在镜面有效区域内采样光线起点。
- [ ] 在太阳视圆内采样入射方向，并固定随机种子或使用 Sobol 序列保证结果可复现。
- [ ] 根据镜面法向量计算每条入射光线的反射方向。
- [ ] 求反射光线与半径 3.5 m 的圆柱侧面的交点。
- [ ] 判断交点高度是否处于 `[76, 84]` m，并排除射线反方向的无效交点。
- [ ] 以到达集热器侧面的光线比例计算 `eta_trunc`。
- [ ] 确保截断效率的分母是已通过阴影遮挡判定的反射能量，避免与 `eta_sb` 重复计算。

## 八、效率与功率汇总

- [ ] 计算单镜光学效率：

  ```text
  eta_i = eta_sb_i * eta_cos_i * eta_at_i * eta_trunc_i * eta_ref
  ```

- [ ] 计算某时刻镜场平均余弦效率、阴影遮挡效率和截断效率。
- [ ] 按镜面面积加权计算某时刻镜场平均光学效率；问题一中等价于单镜效率的算术平均。
- [ ] 不用“各分项平均效率的乘积”代替“单镜总效率的平均”。
- [ ] 计算某时刻镜场输出热功率：

  ```text
  E_field = DNI * sum(A_i * eta_i)
  ```

- [ ] 将输出功率从 kW 转换为 MW。
- [ ] 计算单位镜面面积输出热功率：

  ```text
  q_field = E_field / 62820 = DNI * eta_field
  ```
