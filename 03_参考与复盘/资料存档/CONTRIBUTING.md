# 贡献指南

感谢你考虑为数学建模论文模板项目贡献内容！以下是参与方式。

## 如何贡献

### 报告问题

- 使用 GitHub Issues 报告错误或提出建议
- 请描述清楚：遇到的问题、复现步骤、期望结果

### 提交内容

1. **Fork 本仓库**
2. **创建分支**：`git checkout -b feature/your-feature-name`
3. **提交修改**：`git commit -m "Add: 你的修改说明"`
4. **推送分支**：`git push origin feature/your-feature-name`
5. **发起 Pull Request**

## 贡献方向

| 方向 | 示例 |
|------|------|
| 新增题型 | 图论类、仿真类、博弈类 |
| 补充范例 | 更多真实赛题的摘要范例 |
| 优化模板 | LaTeX 排版改进、宏包更新 |
| 翻译 | 英文版（适配美赛 MCM/ICM） |
| 工具 | 自动化脚本（图表生成、格式检查） |

## 提交规范

- **Markdown 文件**：使用标准 Markdown 语法，中文与英文/数字间留一个空格
- **LaTeX 文件**：确保在 XeLaTeX 下编译通过，使用 `fontset=fandol`
- **命名规范**：文件名用中文或英文均可，但不要包含空格和特殊字符
- **风格一致**：新增内容与现有文档风格保持一致（标题层级、表格格式等）

## Commit 规范

```
<type>: <description>

类型 type:
  Add     新增内容（题型、范例、规范）
  Fix     修复错误（排版、链接、错别字）
  Update  更新内容（方法、规范、版本）
  Refactor 重构（结构调整，不改内容）
  Docs    文档（README、贡献指南）
```

示例：
- `Add: 新增图论类题型专用规范`
- `Fix: 修正摘要六段法中第四段的错误描述`
- `Update: LaTeX模板适配TeX Live 2026`

## 审查流程

1. 维护者会在 7 天内 review 你的 PR
2. 如需修改，请在原分支上更新并 push（不要新建 PR）
3. 通过后合并到 main 分支

## 行为准则

- 尊重所有贡献者
- 建设性反馈，不人身攻击
- 欢迎新手，耐心解答问题
