# 统计分析类专用话术

> 统计分析类题目（假设检验 / 方差分析 / 相关分析 / 卡方检验）的专用学术句式。
> 通用句式见 `../01_通用写作规范/通用学术句式.md`。

---

## 一、统计类问题特征

- 多因素间存在**交互效应**，单因素分析不足。
- 部分组**方差不齐**，标准 ANOVA 不适用。
- 存在**混淆因素**（如降雨量影响产量），简单相关可能误判因果。
- **小样本**（n<30）下参数检验效能低，需非参数替代。
- 需通过**前提检验**确认数据满足假设。

---

## 二、描述性统计

- 对 4 组数据做描述性统计，按 3σ 准则剔除异常值 2 个。
- 剩余 70 个有效样本，各组 $n=17 \sim 18$。
- B 组均值最高 6350±280 kg/ha，D 组最低 5640±310 kg/ha。
- 各组均值差异 710 kg/ha，需检验是否显著。

---

## 三、前提检验

### 正态性
- 对各组做 Shapiro-Wilk 检验，原假设 $H_0$: 数据来自正态分布。
- A 组 $W=0.96, p=0.62$；B 组 $W=0.97, p=0.71$；C 组 $W=0.95, p=0.45$；D 组 $W=0.96, p=0.58$。
- 各组 $p > 0.05$，不拒绝 $H_0$，数据服从正态分布。

### 方差齐性
- Levene 检验：$W=2.14$，$p=0.105 > 0.05$，方差齐性成立，可用标准 ANOVA。
- 若 $p < 0.05$ 则改用 Welch ANOVA 与 Kruskal-Wallis 非参数检验。

### 独立性
- 各试验小区随机分配，假设相互独立，无空间相关性。

---

## 四、假设检验

### t 检验
- 单样本 t 检验：$t = (\bar{x} - \mu_0)/(s/\sqrt{n})$。
- 双样本 t 检验：$t = (\bar{x}_1 - \bar{x}_2)/\sqrt{s_1^2/n_1 + s_2^2/n_2}$。
- 配对 t 检验：对同一组对象前后比较，$t = \bar{d}/(s_d/\sqrt{n})$。
- 检验结果：$t = 5.15 > t_{0.05, 16} = 1.75$，$p = 0.0001 < 0.05$，拒绝 $H_0$。

### 方差分析
- 单因素 ANOVA：$F = MSA/MSE$，$F = 12.34$，$p < 0.001$，组间差异显著。
- 双因素 ANOVA：分解为主效应 + 交互效应 + 误差。
- 施肥主效应显著（$F=12.34, p<0.001$），灌溉主效应显著（$F=8.76, p=0.002$）。
- 交互效应不显著（$p=0.234$），可分别分析主效应。

### 事后多重比较
- ANOVA 显著后，用 **Tukey HSD** 做两两比较，控制族错误率。
- B-A 均值差 530，$p=0.000$，显著（**）。
- C-A 均值差 160，$p=0.482$，不显著（ns）。
- Bonferroni 校正更保守，适合少数比较。

### 非参数检验
- Kruskal-Wallis 检验：$H = \frac{12}{n(n+1)} \sum R_i^2/n_i - 3(n+1)$。
- $H = 22.7$，$p < 0.001$，结论与 ANOVA 一致。
- 适合方差不齐或非正态数据。
- Mann-Whitney U 检验：两组中位数比较的非参数替代。

---

## 五、相关分析

### Pearson 相关
- $r = \sum(x_i - \bar{x})(y_i - \bar{y}) / \sqrt{\sum(x_i - \bar{x})^2 \sum(y_i - \bar{y})^2}$。
- $r = 0.58$，$p = 0.003 < 0.05$，显著正相关。
- Pearson 假设线性关系与正态分布。

### Spearman 秩相关
- 不假设线性关系，基于秩计算。
- $\rho = 0.61$，$p = 0.002$。
- 适合单调非线性关系或定序变量。

### 偏相关
- 控制混淆因素 Z 后的净相关：$r_{XY \cdot Z} = (r_{XY} - r_{XZ} r_{YZ})/\sqrt{(1 - r_{XZ}^2)(1 - r_{YZ}^2)}$。
- 控制降雨量与温度后，施肥量与产量偏相关 $r = 0.72$。
- 较简单相关 $r = 0.58$ 提升 **24.1%**，证实施肥量独立影响显著。

### 卡方检验
- 检验分类变量独立性：$\chi^2 = \sum (O - E)^2/E$。
- $\chi^2 = 18.6 > \chi^2_{0.05, 9} = 16.92$，$p = 0.029 < 0.05$。
- 拒绝独立性原假设，施肥方案与作物等级显著相关。
- 注意：期望频数 $E < 5$ 的格子不超过 20%。

---

## 六、稳健性验证

### Bootstrap
- 对样本做 Bootstrap 重抽样 5000 次。
- 施肥主效应 $p$ 值 95% CI [0.000, 0.003] 均 < 0.05。
- 证明结论在小样本扰动下稳健。

---

## 七、效应量

- Cohen's d = $(\bar{x}_1 - \bar{x}_2)/s_p$，d=0.8 为大效应。
- $\eta^2 = SS_{effect}/SS_{total}$，$\eta^2 = 0.36$ 为大效应。
- p 值仅说明是否显著，效应量说明**显著到什么程度**。
- 大样本下小 p 值不一定有实际意义，必须报效应量。

---

## 八、模型评价

### 优点
- **前提严谨**：Shapiro-Wilk + Levene 双重检验。
- **非参数交叉**：Kruskal-Wallis 验证 ANOVA 结论。
- **控制混淆**：偏相关分离独立效应。

### 缺点
- **小样本局限**：n=70 对复杂模型不足。
- **observational 数据**：非实验设计，因果推断弱。
- **未考虑空间相关**：假设小区独立，实际可能有空间效应。

### 推广
- 可推广至医学疗效、工艺优化、教育评估等场景。
- 可引入协方差分析（ANCOVA）控制连续混淆变量。
- 可用混合效应模型处理重复测量数据。
