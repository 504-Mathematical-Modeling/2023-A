# 统计分析类摘要范例

> 统计分析类题目（假设检验 / 方差分析 / 相关分析 / 卡方检验）的摘要专用范例。
> 通用规范见 `../01_通用写作规范/摘要六段法通用规范.md`。

## 一、统计分析类摘要的必报要素

| 要素 | 必报 | 示例 |
|------|------|------|
| 方法名 | 是 | t 检验 / ANOVA / 偏相关 |
| 检验类型 | 是 | 双因素方差分析 |
| 显著性 | 是 | p<0.05 |
| 检验结果 | 是 | 拒绝 H0 |
| 前提检验 | 是 | Shapiro-Wilk + Levene |
| 效应量 | 强烈建议 | $\eta^2$=0.36 |

## 二、完整范例（统计题 - 方差与相关分析）

> **针对**不同施肥方案对作物产量影响分析中**多因素交互**、**方差不齐**、**相关性混淆**等复杂特征，本文建立了以双因素方差分析为核心、融合非参数检验与偏相关分析的统计推断框架。
>
> **针对问题一**，对 4 种施肥方案 × 3 个灌溉水平的 12 组数据做双因素方差分析。结果显示施肥方案主效应显著（F=**12.34**，p=**0.000** < 0.05），灌溉水平主效应显著（F=**8.76**，p=**0.002**），交互效应不显著（p=0.234）。方案 B 在灌溉水平 2 下均值最高 **6420 kg/ha**。
>
> **针对问题二**，引入 Levene 检验发现部分组方差不齐（p=0.021 < 0.05），改用 Welch ANOVA 与 Kruskal-Wallis 非参数检验。Welch F=**10.82** 仍显著，Kruskal-Wallis H=**22.7**（p<0.001），结论与问题一一致，证明结论稳健。
>
> **针对问题三**，针对"产量与施肥量、降雨量、温度三因素相关性混淆"，构建偏相关分析。控制降雨量与温度后，施肥量与产量的偏相关系数 r=**0.72**（p<0.001），较简单相关 r=0.58 提升 **24.1%**，证实施肥量独立影响显著。
>
> **针对问题四**，对样本量做 Bootstrap 重抽样 5000 次，施肥方案主效应 p 值 95% CI **[0.000, 0.003]** 均 < 0.05，证明结论在小样本扰动下稳健。
>
> 本文统计推断框架可推广至医学疗效、工艺优化、教育评估等场景。

**关键词**：双因素方差分析；非参数检验；偏相关；Bootstrap；Welch ANOVA

## 三、反例与诊断

### 反例 1：不报显著性
> 针对问题一，做方差分析，方案 B 均值最高。

**诊断**：F 值？p 值？统计结论必须报显著性。

### 反例 2：忽略前提检验
> 针对问题一，做 t 检验，p<0.05 拒绝 H0。

**诊断**：t 检验前提是正态 + 方差齐性。必须先报 Shapiro-Wilk 与 Levene 检验，否则结论无效。

```latex
\textbf{针对问题二}，引入【Levene/Shapiro】检验发现【方差不齐/非正态】，改用【Welch ANOVA/Kruskal-Wallis】。F=\res{【数字】}仍显著，结论\res{【与问题一一致】}，证明稳健。

\textbf{针对问题三}，针对【混淆因素】，构建【偏相关/协方差分析】。控制【混淆变量】后，【X 与 Y】偏相关 r=\res{【数字】}（p\res{【<0.001】}），较简单相关\res{【提升/下降】}\res{【百分比】}\%。

\textbf{针对问题四}，对样本做 Bootstrap 重抽样\res{【N】}次，【效应】p 值 95\% CI \res{【【下界】, 【上界】】} \res{【均<0.05】}，证明结论稳健。
```

## 五、统计分析类摘要的指标规范

| 指标 | 报告精度 | 何时必报 |
|------|----------|----------|
| F 值 | 2 位小数 | ANOVA 必报 |
| p 值 | 3 位小数或 < 阈值 | 所有检验必报 |
| 相关系数 r | 2 位小数 | 相关分析必报 |
| 效应量 $\eta^2$/d | 2 位小数 | 强烈建议报 |
| 置信区间 | 与原指标同精度 | Bootstrap 必报 |

---

## 六、一句话总结

> **统计题 = 检验统计量 + p 值 + 前提检验 + 稳健性验证。**
