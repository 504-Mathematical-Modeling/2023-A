## 一、预测类建模决策树

```
数据特征？
├── 时间序列
│   ├── 平稳 → ARMA(p,q)
│   ├── 非平稳 → 差分 → ARIMA(p,d,q)
│   ├── 含趋势/季节 → SARIMA / Holt-Winters
│   ├── 小样本(≥4) → GM(1,1) 灰色预测
│   └── 非线性 → LSTM / Prophet
├── 截面数据（多变量）
│   ├── 线性 → OLS / 岭回归 / LASSO
│   ├── 非线性 → 随机森林 / XGBoost
│   └── 高维共线 → PCA + 回归 / 偏最小二乘
└── 长期外推 → 组合预测（ARIMA + GM + LSTM 加权）
```

## 二、ARIMA 建模标准流程

### 第 1 步：平稳性检验
```latex
\subsubsection{平稳性检验}

对序列 $\{y_t\}_{t=1}^{T}$ 做 ADF 检验：
\begin{equation}
    \Delta y_t = \alpha + \beta t + \gamma y_{t-1} + \sum_{i=1}^{p} \phi_i \Delta y_{t-i} + \epsilon_t
\end{equation}
原假设 $H_0: \gamma=0$（存在单位根）。检验结果：ADF = -2.34，p=0.16 > 0.05，不能拒绝 $H_0$，序列非平稳。

一阶差分 $\Delta y_t = y_t - y_{t-1}$ 后再做 ADF：ADF = -4.82，p=0.0005 < 0.05，序列平稳，故 $d=1$。
```

### 第 2 步：阶数识别
```latex
\subsubsection{阶数识别}

观察 ACF 与 PACF：
\begin{itemize}
    \item ACF 在滞后 2 处截尾 → $q=1$ 候选；
    \item PACF 在滞后 2 处截尾 → $p=2$ 候选。
\end{itemize}
遍历 $p \in \{0,1,2,3\}$, $q \in \{0,1,2\}$，比较 AIC：
\begin{table}[H]
    \centering
    \caption{AIC 选阶结果}
    \begin{tabular}{cccc}
        \toprule
        模型 & AIC & BIC & 对数似然 \\
        \midrule
        ARIMA(1,1,1) & 148.3 & 152.1 & -71.2 \\
        ARIMA(2,1,1) & \textbf{142.6} & 147.8 & -68.3 \\
        ARIMA(2,1,2) & 143.1 & 149.5 & -67.5 \\
        \bottomrule
    \end{tabular}
\end{table}
选 AIC 最小的 ARIMA(2,1,1)。
```

### 第 3 步：参数估计
```latex
\subsubsection{参数估计}

用极大似然估计得到：$\hat{\phi}_1=0.62$（s.e.=0.12），$\hat{\phi}_2=-0.21$（s.e.=0.10），$\hat{\theta}_1=0.45$（s.e.=0.14），均通过 $t$ 检验（$|t|>1.96$）。
```

### 第 4 步：残差检验
```latex
\subsubsection{残差诊断}

\textbf{（1）白噪声检验}：Ljung-Box Q = 5.3，p=0.38 > 0.05，残差为白噪声。

\textbf{（2）正态性检验}：Shapiro-Wilk W=0.97，p=0.42 > 0.05，残差服从正态分布。

\textbf{（3）异方差检验}：ARCH-LM 检验 p=0.21 > 0.05，无 ARCH 效应。

模型诊断通过，可用于预测。
```

## 三、Python 实现速查

### ARIMA（statsmodels）
```python
import pandas as pd
from statsmodels.tsa.arima.model import ARIMA
from statsmodels.stats.diagnostic import acorr_ljungbox

# 拟合
model = ARIMA(y, order=(2,1,1))
result = model.fit()
print(result.summary())

# 残差检验
lb = acorr_ljungbox(result.resid, lags=[10], return_df=True)
print(lb)

# 预测
forecast = result.get_forecast(steps=6)
print(forecast.predicted_mean)
print(forecast.conf_int(alpha=0.05))  # 95% CI
```

### 灰色预测 GM(1,1)
```python
import numpy as np

def gm11(x0, predict_steps=3):
    x1 = np.cumsum(x0)
    z1 = -0.5 * (x1[:-1] + x1[1:])
    B = np.column_stack([z1, np.ones_like(z1)])
    Y = x0[1:]
    a, b = np.linalg.lstsq(B, Y, rcond=None)[0]
    
    # 预测
    x1_pred = (x0[0] - b/a) * np.exp(-a * np.arange(1, len(x0)+predict_steps)) + b/a
    x0_pred = np.diff(np.concatenate([[x0[0]], x1_pred]))
    
    # 精度
    residual = x0 - x0_pred[:len(x0)]
    c = np.std(residual) / np.std(x0)  # 后验差比值
    return x0_pred, a, b, c
```

### LSTM（PyTorch）
```python
import torch
import torch.nn as nn

class LSTMForecaster(nn.Module):
    def __init__(self, input_size=1, hidden=32, layers=2):
        super().__init__()
        self.lstm = nn.LSTM(input_size, hidden, layers, batch_first=True)
        self.fc = nn.Linear(hidden, 1)
    
    def forward(self, x):
        out, _ = self.lstm(x)
        return self.fc(out[:, -1, :])

# 训练
model = LSTMForecaster()
criterion = nn.MSELoss()
optimizer = torch.optim.Adam(model.parameters(), lr=0.01)
for epoch in range(200):
    optimizer.zero_grad()
    loss = criterion(model(X_train), y_train)
    loss.backward()
    optimizer.step()
```

## 四、组合预测写法

### 加权组合
```latex
\subsubsection{组合预测}

设 ARIMA、GM(1,1)、LSTM 三个单模型预测值为 $\hat{y}_t^{(1)}, \hat{y}_t^{(2)}, \hat{y}_t^{(3)}$，组合预测：
\begin{equation}
    \hat{y}_t = \sum_{k=1}^{3} w_k \hat{y}_t^{(k)}, \quad \sum w_k = 1
\end{equation}
权重由熵权法确定（基于各单模型 RMSE）：$w_1=0.45, w_2=0.20, w_3=0.35$。
```

## 六、避坑指南

### 坑 1：未做平稳性检验直接 ARIMA
**对策**：必须先 ADF 检验，确定 $d$。

### 坑 2：阶数凭感觉
**对策**：用 AIC/BIC 选阶，遍历 $p \in [0,3]$、$q \in [0,3]$，列表对比。

### 坑 3：过拟合
**对策**：训练集 + 验证集划分（如前 80% 训练，后 20% 验证），报告验证集 RMSE。

### 坑 4：长期外推无区间
**对策**：长期预测必须报 95% CI，并说明区间随时间变宽。

### 坑 5：LSTM 无归一化
**对策**：LSTM 输入必须标准化（`StandardScaler`），否则不收敛。

### 坑 6：灰色预测用错场景
**对策**：GM(1,1) 仅适合**指数增长**的小样本（≥4），不适合波动序列。

## 八、一句话总结

> **ARIMA 必走四步（ADF→AIC→MLE→残差检验），长期必报 95% CI，组合必有权重依据。**
