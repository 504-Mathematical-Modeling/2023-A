# 机理建模类专用话术

> 机理建模类题目（ODE / PDE / Runge-Kutta / 差分方程 / 元胞自动机）的专用学术句式。
> 通用句式见 `../01_通用写作规范/通用学术句式.md`。

---

## 一、问题特征描述

- 系统演化遵循**守恒律**（质量/能量/动量守恒），可从物理机理推导方程。
- 存在**边界条件**与**初始条件**约束，构成定解问题。
- **稳态存在性**需通过平衡点分析验证。
- **参数辨识**依赖实验/历史数据，需报告拟合精度。
- **数值稳定性**受网格步长与格式影响，需满足 CFL 等条件。

---

## 二、机理推导句式

### 基于守恒律
- 基于**质量守恒定律**，考虑微元体 $\Delta V$ 内质量变化率等于流入减流出加源汇：
  $\frac{\partial C}{\partial t} = -\nabla \cdot (C\mathbf{v}) + D\nabla^2 C + S$。
- 基于**能量守恒**，微元体内能变化等于热传导输入加体积热源：
  $\rho c_p \frac{\partial T}{\partial t} = k \nabla^2 T + Q$。

### 基于反应律
- 基于**Logistic 增长律**，资源限制导致密度制约：
  $\frac{dN}{dt} = rN(1 - \frac{N}{K})$，其中 $\frac{N}{K}$ 项体现资源限制。
- 基于**质量作用定律**，反应速率与反应物浓度乘积成正比：
  $\frac{dC_A}{dt} = -kC_A C_B$。

### 基于扩散律
- 基于**Fick 扩散定律**，扩散通量与浓度梯度成正比：
  $J = -D\nabla C$，代入守恒方程得扩散项 $D\nabla^2 C$。
- 基于**Newton 冷却定律**，边界热交换 $-k\frac{\partial T}{\partial n} = h(T - T_\infty)$。

## 三、边界条件句式

### 初始条件
- **初始条件**：$C(x, 0) = 0$，$x > 0$（河段初始无污染）。
- **初始分布**：$N(x, 0) = N_0 e^{-x^2/2\sigma^2}$（高斯型初始分布）。

### 边界条件
- **第一类（Dirichlet）**：$C(0, t) = C_0$（上游恒定排放）。
- **第二类（Neumann）**：$\frac{\partial C}{\partial x}|_{x=L} = 0$（下游无穷远条件/零通量）。
- **第三类（Robin）**：$-D\frac{\partial C}{\partial x}|_{x=0} = h(C_0 - C(0,t))$（对流交换边界）。
- 边界条件与初始条件共同构成**定解问题**。

## 四、数值求解句式

### 有限差分
- 采用**Crank-Nicolson 隐式格式**（时间二阶、空间二阶精度）：
  $\frac{C_i^{n+1} - C_i^n}{\Delta t} = \frac{D}{2}[\frac{C_{i+1}^{n+1} - 2C_i^{n+1} + C_{i-1}^{n+1}}{\Delta x^2} + \frac{C_{i+1}^n - 2C_i^n + C_{i-1}^n}{\Delta x^2}]$。
- 隐式格式**无条件稳定**，每步需解三对角线性方程组（追赶法）。
- 显式格式需满足 $D\Delta t/\Delta x^2 < 0.5$（稳定性条件），否则数值爆炸。

### Runge-Kutta
- 对刚性 ODE 采用**四阶 Runge-Kutta**：
  $y_{n+1} = y_n + \frac{h}{6}(k_1 + 2k_2 + 2k_3 + k_4)$，局部截断误差 $O(h^5)$。
- 用 `scipy.integrate.solve_ivp`（method='RK45'）自适应步长求解。
- 刚性系统改用 BDF 或 Radau 方法。

### CFL 条件
- 对流方程显式格式需满足 **CFL 条件**：$|v|\Delta t/\Delta x \leq 1$。
- 物理意义：时间步长内信息传播距离不超过一个网格。

## 五、稳态分析句式

### 平衡点求解
- 令 $\frac{dN}{dt}=0$，得平衡点 $N^*=0$ 与 $N^*=K$。
- 令 $\frac{\partial C}{\partial t}=0$ 求稳态解，得 $C^*(x) = C_0 e^{\alpha x}$。

### 线性化与特征值
- 在 $N^*=K$ 处线性化：令 $N = K + \epsilon$，则 $\frac{d\epsilon}{dt} \approx -r\epsilon$。
- 特征值 $\lambda = -r < 0$，故 $N^*=K$ 为**稳定结点**。
- $\lambda < 0$ 稳定，$\lambda > 0$ 不稳定，$\lambda$ 为复数则振荡。

### 相图分析
- 绘制相图（图 \ref{fig:phase}），可见所有 $N_0 > 0$ 的轨迹均收敛至 $N^*=K$。
- 相图显示系统存在**吸引子** $N^*=K$，**排斥子** $N^*=0$。

## 六、参数辨识句式

### 最小二乘辨识
- 设模型预测 $\hat{y}(t;\theta)$，参数 $\theta=(r, K)$。最小化残差平方和：
  $\min_\theta \sum_{i=1}^{n}(y_i - \hat{y}(t_i;\theta))^2$。
- 用 L-BFGS-B 求解，得 $\hat{r}=0.23$/d，$\hat{K}=1000$。

### 拟合精度
- 拟合优度 $R^2 = 1 - SS_{res}/SS_{tot} = 0.982$，模型解释 98.2% 方差。
- 均方根误差 $RMSE = \sqrt{\frac{1}{n}\sum(y_i - \hat{y}_i)^2} = 12.3$。
- $R^2 > 0.9$ 且 RMSE < 数据标准差的 1/2，拟合良好。

### 参数灵敏度
- 对参数 $r$、$K$ 做 ±20% 扰动，预测值变化 < 5%，模型对参数**不敏感**。
- 灵敏度系数 $S_{ij} = \frac{\partial y_i}{\partial \theta_j}\frac{\theta_j}{y_i}$。

## 七、结果呈现句式

### 必含三要素
1. **解的曲线**（解析或数值）：随时间/空间演化曲线。
2. **稳态分析**（平衡点 + 稳定性）：体现数学深度。
3. **参数辨识精度**（$R^2$, RMSE）：证明模型可信。

### 结果描述
- 模型预测种群数量随时间变化曲线见图 \ref{fig:pop}，预测 30 天后种群规模 **985**（接近 $K=1000$）。
- 稳态分析表明 $N^*=K=1000$ 为稳定平衡点，所有 $N_0 > 0$ 轨迹均收敛至此。
- 参数辨识 $R^2=0.982$，RMSE=12.3，模型拟合良好。
- 预测 6 小时后 $x=2$ km 处浓度 **32.4** mg/L，与稳态解 30.1 mg/L 偏差 7.1%，验证数值解正确性。

## 八、模型评价

### 优点
- **机理解释强**：基于守恒律推导，物理意义明确，非黑箱。
- **外推能力强**：机理确定后可外推至未观测场景。
- **稳态可分析**：平衡点与稳定性分析提供解析洞察。
- **可解释参数**：每个参数有明确物理意义（$r$ 增长率、$K$ 容量、$D$ 扩散系数）。

### 缺点
- **机理假设强**：守恒律/反应律简化可能偏离实际。
- **参数辨识难**：复杂模型参数多，数据不足时辨识不准。
- **数值求解复杂**：PDE 隐式格式编程复杂，计算量大。
- **边界条件敏感**：边界条件选取不当导致解失真。

### 推广
- 可推广至传染病预测、反应器设计、生态保护等场景。
- 可耦合随机项扩展为随机微分方程（SDE）处理不确定性。
- 可引入延迟项扩展为延迟微分方程（DDE）处理时滞效应。
- 可与统计方法结合，用统计辨识参数、机理建方程。

## 十、一句话总结

> **机理推导（守恒律）→ 定解条件（初值+边界）→ 数值求解（隐式格式）→ 稳态分析（平衡点+稳定性）→ 参数辨识（最小二乘 + R² + RMSE）。**
