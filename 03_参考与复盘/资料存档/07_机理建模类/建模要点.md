# 机理建模类要点：微分方程

> 机理建模类题型的守恒律推导、边界条件、数值求解、稳态分析。
> 通用四小节结构见 `../01_通用写作规范/通用四小节结构.md`。

## 一、机理建模三步法

```
1. 机理分析（守恒律/反应律/扩散律）→ 推导微分方程
2. 边界条件与初始条件 → 定解问题
3. 数值求解（有限差分/Runge-Kutta）→ 稳态分析
```

---

## 二、常见机理模型类型

| 类型 | 控制方程 | 典型场景 |
|------|----------|----------|
| 一阶 ODE | $\frac{dy}{dt} = f(t,y)$ | 种群增长、反应速率 |
| 二阶 ODE | $y'' + py' + qy = 0$ | 振动、电路 |
| 偏微分方程 PDE | $\frac{\partial u}{\partial t} = D \nabla^2 u$ | 扩散、传热 |
| 差分方程 | $y_{n+1} = f(y_n)$ | 离散时间 |
| 元胞自动机 | 网格状态演化 | 流行病、交通 |
| 系统动力学 | 反馈回路 | 宏观系统 |

## 三、一阶 ODE 建模（种群增长为例）

### 机理推导
```latex
\subsubsection{模型推导}

设 $t$ 时刻种群数量为 $N(t)$，环境容量 $K$，内禀增长率 $r$。基于 Logistic 增长律：
\begin{equation}
    \frac{dN}{dt} = r N \left(1 - \frac{N}{K}\right), \quad N(0) = N_0
    \label{eq:logistic}
\end{equation}
其中 $\frac{N}{K}$ 项体现资源限制导致的密度制约。
```

### 解析解
```latex
\subsubsection{解析解}

分离变量积分：
\begin{equation}
    N(t) = \frac{K}{1 + \left(\frac{K}{N_0} - 1\right) e^{-rt}}
\end{equation}
稳态分析：令 $\frac{dN}{dt}=0$，得 $N^*=0$（不稳定）或 $N^*=K$（稳定）。
```

### 参数辨识
```latex
\subsubsection{参数辨识}

用最小二乘法拟合历史数据估计 $r=0.23$/d, $K=1000$。拟合优度 $R^2=0.982$。
```

## 四、偏微分方程（扩散模型）

### 机理推导（一维对流扩散）
```latex
\subsubsection{对流扩散方程推导}

考虑污染物在河流中的传输，基于质量守恒：
\begin{equation}
    \frac{\partial C}{\partial t} = D \frac{\partial^2 C}{\partial x^2} - v \frac{\partial C}{\partial x} - k C
    \label{eq:pde}
\end{equation}
其中 $D$ 为扩散系数，$v$ 为流速，$k$ 为降解速率。三项分别表示：扩散、对流、降解。
```

### 边界与初始条件
```latex
\subsubsection{定解条件}

\textbf{初始条件}：$C(x, 0) = 0$，$x > 0$（河段初始无污染）。

\textbf{边界条件}：
\begin{itemize}
    \item 上游 $x=0$：$C(0, t) = C_0$（恒定排放）；
    \item 下游 $x=L$：$\frac{\partial C}{\partial x}\big|_{x=L} = 0$（无穷远条件）。
\end{itemize}
```

### 数值求解（有限差分）
```latex
\subsubsection{有限差分求解}

采用 Crank-Nicolson 格式（隐式，无条件稳定）：
\begin{equation}
    \frac{C_i^{n+1} - C_i^n}{\Delta t} = \frac{D}{2} \left[\frac{C_{i+1}^{n+1} - 2C_i^{n+1} + C_{i-1}^{n+1}}{\Delta x^2} + \frac{C_{i+1}^n - 2C_i^n + C_{i-1}^n}{\Delta x^2}\right] - \cdots
\end{equation}
网格 $\Delta x = 50$ m, $\Delta t = 60$ s。每步求解三对角线性方程组（追赶法）。
```

### Python 实现
```python
import numpy as np
from scipy.linalg import solve_banded

def crank_nicolson(D, v, k, L, T, dx, dt, C0):
    nx = int(L/dx) + 1
    nt = int(T/dt) + 1
    x = np.linspace(0, L, nx)
    C = np.zeros((nt, nx))
    C[:, 0] = C0  # 边界
    
    r = D*dt/(2*dx**2)
    s = v*dt/(4*dx)
    
    # 构造三对角矩阵
    ab = np.zeros((3, nx-2))
    ab[0, 1:] = -(r + s)  # 上对角
    ab[1, :] = 1 + 2*r + k*dt/2  # 主对角
    ab[2, :-1] = -(r - s)  # 下对角
    
    for n in range(nt-1):
        b = (r+s)*C[n, :-2] + (1-2*r-k*dt/2)*C[n, 1:-1] + (r-s)*C[n, 2:]
        b[0] += (r+s)*C0
        C[n+1, 1:-1] = solve_banded((1,1), ab, b)
        C[n+1, 0] = C0
        C[n+1, -1] = C[n+1, -2]  # 下游边界
    
    return x, C
```

## 五、Runge-Kutta 求解 ODE

### 四阶 RK 公式
```latex
\subsubsection{四阶 Runge-Kutta}

对 $\frac{dy}{dt} = f(t,y)$：
\begin{align}
    k_1 &= f(t_n, y_n) \\
    k_2 &= f(t_n + h/2, y_n + hk_1/2) \\
    k_3 &= f(t_n + h/2, y_n + hk_2/2) \\
    k_4 &= f(t_n + h, y_n + hk_3) \\
    y_{n+1} &= y_n + \frac{h}{6}(k_1 + 2k_2 + 2k_3 + k_4)
\end{align}
局部截断误差 $O(h^5)$。
```

### Python 实现
```python
from scipy.integrate import solve_ivp

def lotka_volterra(t, z, a, b, c, d):
    x, y = z
    return [a*x - b*x*y, c*x*y - d*y]

sol = solve_ivp(lotka_volterra, [0, 50], [10, 5], 
                args=(1.1, 0.4, 0.1, 0.4), 
                method='RK45', dense_output=True)
```

## 六、差分方程（离散时间）

### SIR 传染病模型
```latex
\subsubsection{SIR 离散模型}

将人群分为易感 $S$、感染 $I$、康复 $R$：
\begin{align}
    S_{n+1} &= S_n - \beta S_n I_n / N \\
    I_{n+1} &= I_n + \beta S_n I_n / N - \gamma I_n \\
    R_{n+1} &= R_n + \gamma I_n
\end{align}
基本再生数 $R_0 = \beta / \gamma$。当 $R_0 > 1$ 时疫情扩散，$R_0 < 1$ 时收敛。
```

## 七、稳态与稳定性分析

### 平衡点求解
```latex
\subsubsection{平衡点与稳定性}

令 $\frac{dN}{dt}=0$，得平衡点 $N^*=0$ 与 $N^*=K$。

在 $N^*=K$ 处线性化：令 $N = K + \epsilon$，则 $\frac{d\epsilon}{dt} \approx -r \epsilon$，特征值 $\lambda = -r < 0$，故 $N^*=K$ 为稳定结点。
```

## 八、参数辨识

### 最小二乘辨识
```latex
\subsubsection{参数辨识}

设模型预测 $\hat{y}(t; \theta)$，参数 $\theta=(r, K)$。最小化残差平方和：
\begin{equation}
    \min_\theta \sum_{i=1}^{n} (y_i - \hat{y}(t_i; \theta))^2
\end{equation}
用 L-BFGS-B 求解，得 $\hat{r}=0.23$/d, $\hat{K}=1000$，$R^2=0.982$，RMSE=12.3。
```

## 十、避坑指南

### 坑 1：方程无推导直接给
**对策**：必须从守恒律/反应律推导，写出物理意义。

### 坑 2：无边界条件
**对策**：PDE 必须给初始 + 边界条件，否则无定解。

### 坑 3：数值格式不稳定
**对策**：扩散方程用 Crank-Nicolson（隐式）无条件稳定；显式格式需满足 $D\Delta t/\Delta x^2 < 0.5$。

### 坑 4：参数无辨识依据
**对策**：参数必须有来源（文献/实验/最小二乘辨识 + $R^2$）。

### 坑 5：无稳态分析
**对策**：机理模型必须分析平衡点与稳定性，体现数学深度。
