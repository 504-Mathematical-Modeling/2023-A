## 五、Prompt 5：ARIMA 模型识别

```
你是时间序列分析专家。请基于以下时间序列数据，完成 ARIMA 建模：
1. 平稳性检验（ADF 检验，报告 t 统计量与 p 值，确定 d）；
2. 阶数识别（遍历 p∈[0,3], q∈[0,3]，按 AIC 选优，输出对比表）；
3. 参数估计（MLE，报告系数 + 标准误 + t 检验）；
4. 残差诊断（Ljung-Box 白噪声 + Shapiro-Wilk 正态性）；
5. 预测未来 6 期，给出点预测与 95% CI；
6. 用 Python statsmodels 实现的完整代码。

【数据】：
[粘贴时间序列数据，含时间索引]

【要求】：
- 必须报告 AIC 选阶表
- 残差检验必须报告 p 值
- 预测必须给置信区间
```

## 八、Prompt 8：方差分析

```

1. 描述性统计（n、均值±标准差、min、max）；

5. 若方差不齐，改用 Welch ANOVA + Kruskal-Wallis 交叉验证；
6. 事后多重比较（Tukey HSD）；
7. Bootstrap 5000 次稳健性验证；
8. Python scipy + statsmodels 完整代码。

【数据】：
[分组数据]

【要求】：
- 必须先做前提检验
- 必须报告效应量（η²）
- 必须做 Bootstrap
```

## 十二、AI 协作使用规范（2026 国赛）

### 必须声明
- 工具名称与版本（如 ChatGPT-4、Claude-3.5）
- 使用场景（润色/调试/思路/数据整理）
- 1-3 次典型交互实例
- 人工修改与核验说明

### 禁止行为
- 直接照搬 AI 生成内容
- 用 AI 编造数据或文献
- 用 AI 完成全部建模（核心建模必须人工）
- 不声明使用 AI

### 推荐工作流
1. AI 生成初稿 → 人工核验修改 → 最终定稿
2. AI 辅助调试代码 → 人工理解每行逻辑
3. AI 提供思路 → 人工判断与选择
4. 全程保留交互记录备查

### AI 声明模板（LaTeX）
```latex
\section*{AI 工具使用声明}
本队伍使用了 AI 工具：
\begin{itemize}
    \item 工具：ChatGPT-4 / Claude-3.5
    \item 场景：语言润色 / 代码调试 / 模型思路
    \item 交互实例：[1-3 次核心交互]
    \item 核验：所有 AI 输出均经人工核实修正
\end{itemize}
```
