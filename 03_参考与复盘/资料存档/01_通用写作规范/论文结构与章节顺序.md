# 论文结构与章节顺序

> 数学建模竞赛论文的"八段式"标准结构、字数分配、标题公式。
> 适用于国赛/华数杯/MathorCup/电工杯/深圳杯/亚太赛等主流赛事。

---

## 一、八段式结构与字数分配

以正文 20 页（约 12000 字）为基准的字数分配表：

| 序号 | 章节 | 字数 | 占比 | 重点 |
|------|------|------|------|------|
| 摘要 | 摘要 | 600-900 字 | 一页 | **决定生死**，详见 `摘要六段法通用规范.md` |
| 一 | 问题重述 | 400-600 字 | 4% | 不能照抄原题 |
| 二 | 问题分析 | 800-1200 字 | 8% | 解释"为什么选这方法" |
| 三 | 模型假设 | 200-400 字 | 3% | 每条假设都要合理 |
| 四 | 符号说明 | 1 页表格 | 3% | 三线表，统一命名 |
| 五 | 模型建立与求解 | 7000-9000 字 | 65% | **核心**，按 Q1/Q2/Q3/Q4 分小节 |
| 六 | 模型检验与敏感性分析 | 1000-1500 字 | 8% | 灵敏度 + 误差 + 稳定性 |
| 七 | 模型评价与推广 | 600-900 字 | 5% | 优点/缺点/推广三段式 |
| — | 参考文献 | — | 1% | GB/T 7714，5-15 篇 |
| — | 附录 | 不限 | — | 代码 + 完整数据表 |

> **铁律**：摘要 + 模型建立与求解 = 全文 70% 分量。其余章节是为这两部分服务的。

## 二、各章节标题公式

### 摘要标题
```
居中、加粗、三号字：「摘  要」（两字间空两格）
```

### 一级标题（用中文数字）
```
一、问题重述
二、问题分析
三、模型假设
四、符号说明
五、模型的建立与求解
六、模型检验与敏感性分析
七、模型评价与推广
八、参考文献
```
> 国赛官方要求一级标题用中文数字"一、二、三、"，**不要**用"1. 2. 3."。

### 五（模型建立）下的二级标题
推荐按问题切分：
```
5.1 问题一：[方法名]模型的建立与求解
5.2 问题二：引入[新约束/新因素]的扩展模型
5.3 问题三：[规模特征/双层/启发式]的求解
5.4 问题四：[随机性/预测/敏感性]的处理
```

### 二级标题下的三级标题（推荐四小节结构）
每个问题下统一用：
```
5.1.1 模型目标
5.1.2 约束条件（或：变量关系）
5.1.3 求解算法
5.1.4 求解结果
```
详见 `通用四小节结构.md`。

## 三、标题写作公式（拿来即用）

### 问题一标题公式
```
5.1 问题一：基于【方法】的【目标】模型
例：5.1 问题一：基于混合整数线性规划的最低成本排产模型
```

### 问题二标题公式
```
5.2 问题二：引入【新约束/新因素】的【方法】扩展模型
例：5.2 问题二：引入产能耦合约束的 MILP 扩展模型
```

### 问题三标题公式
```
5.3 问题三：基于【双层/启发式】框架的【大规模特征】求解
例：5.3 问题三：基于遗传算法与拉格朗日松弛的双层求解框架
```

### 问题四标题公式
```
5.4 问题四：基于【预测/分布拟合】与【验证方法】的【随机特征】分析
例：5.4 问题四：基于 ARIMA 与蒙特卡洛模拟的随机需求鲁棒性分析
```

## 四、章节顺序的硬性规定（国赛）

1. **摘要必须单独成页**，关键词在摘要末尾。
2. **目录可选**，国赛一般不要求；华数杯等赛事可加。
3. **页码**：摘要页用阿拉伯数字从 1 开始编号（部分赛事要求摘要不计页码，按当年要求）。
4. **AI 使用声明**（2026 国赛新规）：位于正文结束、参考文献之前。详见 `../AI使用规范.txt`。
5. **附录**：放代码和完整数据表，正文只放代表性结果。

## 五、正反例对照

### 反例：章节顺序混乱
```
一、问题重述
二、模型假设        ← 跳过了问题分析
三、符号说明
四、问题分析        ← 顺序倒了
五、模型的建立...
```
**问题**：评卷人按惯例找"问题分析"找不到，影响阅读体验。

### 正例：标准顺序
```
摘 要
一、问题重述
二、问题分析
三、模型假设
四、符号说明
五、模型的建立与求解
六、模型检验与敏感性分析
七、模型评价与推广
AI 工具使用声明
八、参考文献
附录 A 完整数据表
附录 B 核心源代码
```

## 六、LaTeX 实现速查

```latex
% 摘要单独成页（已封装为命令）
\abstractpage{论文标题}{摘要六段正文}

% 一级标题（ctexart 自动用中文数字）
\section{问题重述}
\section{问题分析}
\section{模型假设}
\section{符号说明}
\section{模型的建立与求解}
\section{模型检验与敏感性分析}
\section{模型评价与推广}

% AI 声明（不计入章节编号）
\section*{AI 工具使用声明}
\addcontentsline{toc}{section}{AI 工具使用声明}

% 参考文献
\section{参考文献}
\begin{thebibliography}{99}
    \bibitem{1} ...
\end{thebibliography}

% 附录
\appendix
\section*{附录 A：完整数据表}
\section*{附录 B：核心源代码}
```

## 七、字数超限怎么办

| 章节 | 超字数时优先删什么 |
|------|---------------------|
| 摘要 | 删背景套话，每个 Q 只留方法名 + 核心数字 |
| 问题重述 | 删原题复述，只保留"已知条件 + 任务" |
| 问题分析 | 删方法对比的冗长描述，改为表格对比 |
| 模型建立 | 把推导细节移入附录，正文只放最终方程 |
| 模型检验 | 多张灵敏度表合并为一张 |

## 八、一句话总结

> **八段式骨架不能乱，字数向"摘要 + 模型建立"集中，标题用公式套，章节顺序严格按规范。**
