# 提交前检查清单

> 提交前逐项勾选，10 类 50+ 项检查。
> 任何一项未通过都可能导致扣分或退赛。

---

## 一、摘要（最重要）

- [ ] 摘要单独成页，页码从 1 开始
- [ ] 标题居中加粗"摘  要"（两字间空两格）
- [ ] 严格六段：背景 / Q1 / Q2 / Q3 / Q4 / 总结
- [ ] 每段开头"针对..."领起
- [ ] 第 2-5 段每段至少一个加粗数字结果
- [ ] 方法名出现（MILP/ARIMA/TOPSIS/K-means 等）
- [ ] 总字数 600-900，不超一页
- [ ] 关键词 5 个，按"方法→对象→目标"排序
- [ ] 关键词非泛词（避免"数学建模""优化""模型"）

---

## 二、结构与标题

- [ ] 一级标题用中文数字（一、二、三、）
- [ ] 八段式顺序：重述→分析→假设→符号→建模→检验→评价→文献
- [ ] AI 使用声明在参考文献之前（2026 国赛新规）
- [ ] 附录在参考文献之后
- [ ] 章节标题不超过 3 级
- [ ] 无空白章节（每个标题下有内容）

---

## 三、问题重述

- [ ] 字数 400-600，不超 1 页
- [ ] 不照抄原题
- [ ] 已知条件结构化（编号列表）
- [ ] 任务转化为"求使 XX 最小的 YY 方案"
- [ ] 四问转化表（对象/目标/约束/输出）

---

## 四、问题分析

- [ ] 每个问题有"特征 + 方法对比 + 选择依据 + 递进关系"四段
- [ ] 至少 2-3 个候选方法对比
- [ ] 技术路线图（必画）
- [ ] 不报具体数字结果（那是摘要的事）
- [ ] 不写方程（那是模型建立的事）

---

## 五、模型假设与符号

### 假设
- [ ] 5-8 条假设
- [ ] 每条有依据（题目/常识/文献）
- [ ] 分布假设配套检验（Shapiro-Wilk/ADF/Ljung-Box）
- [ ] 假设之间不矛盾
- [ ] 假设与正文一致

### 符号
- [ ] 一张三线表
- [ ] 所有正文符号都在表内
- [ ] 同一符号全文含义一致
- [ ] 单位标注完整（复合单位如 元/(件·周)）
- [ ] 下标有语义（i/t/j/k）
- [ ] 决策变量小写、参数大写

---

## 六、模型建立与求解

### 通用
- [ ] 每个问题下四小节：目标→约束→算法→结果
- [ ] 每条约束有公式 + 文字解释
- [ ] 每个公式有编号（\label）
- [ ] 算法步骤可复现（参数给具体值）
- [ ] 结果数字加粗（\res{}）
- [ ] 至少一张图或表

### 优化类
- [ ] 目标函数 + 至少 3 类约束
- [ ] 求解器与参数（Gurobi/CBC + timeLimit/MIPGap）
- [ ] 大规模问题报求解时间
- [ ] 与基线对比（贪心/精确）

### 预测类
- [ ] ADF 平稳性检验
- [ ] AIC/BIC 选阶表
- [ ] 参数估计 + 标准误 + t 检验
- [ ] 残差检验（Ljung-Box + Shapiro-Wilk）
- [ ] 预测值 + 95% CI
- [ ] 历史 + 预测对比图

### 评价类
- [ ] 指标体系（维度 + 指标数）
- [ ] AHP 报 CR < 0.1
- [ ] TOPSIS 报 $d^+/d^-/C_i$
- [ ] 排序表
- [ ] 灵敏度分析

### 分类类
- [ ] K 值确定（肘部 + 轮廓 + CH）
- [ ] 轮廓系数
- [ ] 5 折交叉验证
- [ ] 混淆矩阵
- [ ] 特征重要度

### 统计类
- [ ] 描述性统计表
- [ ] Shapiro-Wilk + Levene 前提检验
- [ ] ANOVA 完整表（SS/df/MS/F/p）
- [ ] 事后 Tukey HSD
- [ ] 非参数交叉验证
- [ ] Bootstrap 稳健性

### 机理类
- [ ] 控制方程推导（守恒律）
- [ ] 初始 + 边界条件
- [ ] 数值格式稳定性说明
- [ ] 稳态分析（平衡点 + 稳定性）
- [ ] 参数辨识 $R^2$

---

## 七、模型检验

- [ ] 灵敏度分析（±20% 至少一个参数）
- [ ] 灵敏度表格 + 结论文字
- [ ] 误差分析（R² + RMSE + MAPE）（预测/机理必做）
- [ ] 残差检验（白噪声 + 正态）
- [ ] 5 折 CV（预测/分类必做）
- [ ] 算法收敛曲线（启发式必做）
- [ ] 蒙特卡洛 ≥ 1000 次
- [ ] 解的鲁棒性（优化类）

- [ ] 缺点 2-3 条，每条说"忽略什么 + 偏差方向"
- [ ] 推广 2-3 条，每条说"推广到哪 + 怎么改"
- [ ] 优缺点不矛盾
- [ ] 字数 600-900

## 十三、紧急情况处理

| 紧急情况 | 应急方案 |
|----------|----------|
| LaTeX 编译崩溃 | 用 Overleaf 在线编译，或转 Word |
| 求解器无解 | 放松约束（大 M 调小、产能放宽） |
| 数据异常值多 | 用 IQR 替代 3σ，或用中位数替代均值 |
| 摘要超字数 | 删背景套话，每 Q 只留方法+数字 |
| 时间不够 | 优先保摘要 + Q1 + Q2，简化 Q3/Q4 |
| AI 声明遗漏 | 立即补在参考文献前，附交互记录 |
