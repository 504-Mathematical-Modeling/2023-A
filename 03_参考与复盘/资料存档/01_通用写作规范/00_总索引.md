## 三、六大题型快速索引

### 02_优化类
- **适用场景**：生产排程、路径规划（VRP）、资源分配、背包问题
- **核心方法**：MILP / LP / 动态规划 / 遗传算法 / 模拟退火
- **关键文件**：`02_优化类/建模要点.md`（MILP 约束写法 + 启发式设计）

### 03_预测类
- **适用场景**：时间序列预测、回归预测、中长期外推
- **核心方法**：ARIMA / GM(1,1) / LSTM / 回归 / 组合预测
- **关键文件**：`03_预测类/建模要点.md`（ARIMA 四步流程 + 组合预测）

### 04_评价类
- **适用场景**：方案评价、综合排名、质量评估
- **核心方法**：AHP / 熵权法 / TOPSIS / 模糊综合 / 灰色关联
- **关键文件**：`04_评价类/建模要点.md`（权重确定 + TOPSIS 流程）

### 05_分类类
- **适用场景**：客户分群、模式识别、判别分类
- **核心方法**：K-means / DBSCAN / 层次聚类 / 随机森林 / SVM
- **关键文件**：`05_分类类/建模要点.md`（K 值确定 + 判别分析）

### 06_统计分析类
- **适用场景**：假设检验、方差分析、相关分析、实验设计
- **核心方法**：t 检验 / ANOVA / 卡方检验 / Bootstrap
- **关键文件**：`06_统计分析类/建模要点.md`（前提检验 + ANOVA + 事后比较）

### 07_机理建模类
- **适用场景**：种群增长、扩散传热、传染病、振动系统
- **核心方法**：ODE / PDE / 差分方程 / Runge-Kutta / 稳态分析
- **关键文件**：`07_机理建模类/建模要点.md`（守恒律推导 + 数值求解 + 稳态分析）

## 四、使用流程

### 赛前准备
1. 阅读 `项目复盘与五条铁律.md`，了解历史经验教训
2. 熟悉 `论文结构与章节顺序.md`，掌握整体框架
3. 浏览 `00_LaTeX基础模板与排版/数学建模论文通用LaTeX模板.tex`，搭建论文骨架

### 赛中写作
1. **判断题型**：根据题目特征，对照"六大题型快速索引"确定所属题型
2. **查阅专用文件**：进入对应题型文件夹，查阅 `问题分析要点.md`、`建模要点.md`
3. **写摘要**：先看 `摘要六段法通用规范.md`，再看对应题型的 `摘要范例.md`
4. **写正文**：按 `通用四小节结构.md` 组织模型建立与求解章节
5. **润色**：参考 `通用学术句式.md` 与对应题型的 `专用话术.md`

### 赛后提交
1. 对照 `提交前检查清单.md` 逐项检查
2. 用 LaTeX 编译，确认排版符合 `LaTeX排版规则.md`

## 五、核心原则速记

1. **摘要六段法**：背景+总方法 / Q1 / Q2 / Q3 / Q4 / 总结，每段必含加粗数字结果
2. **问题分析用陈述式**：用"模型选择依据"作为标题，不用"为什么选 XX 模型？"式提问
3. **图题在下、表题在上**：图标题在图下方，表标题在表上方
4. **三线表无竖线**：表格一律用 booktabs 三线表
5. **参考文献顺序**：正文引用用方括号序号（非上标），文献按正文出现顺序排列
6. **加粗关键数字**：摘要与正文中的关键结果数字用 `\res{}` 命令加粗
7. **单位统一**：所有变量统一单位，符号表核对
8. **结果必对比基线**：优化类对比贪心算法，预测类对比单一模型，评价类做灵敏度
