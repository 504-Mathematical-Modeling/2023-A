# 摘要六段法通用规范

> 摘要是数学建模论文中**最重要**的一页。评卷人 30 秒内决定是否细读全文。
> 本规范适用于所有六大题型，给出铁律 + 黄金模板 + 正反例 + LaTeX 代码。

---

## 一、六段法铁律

摘要必须严格分**六段**，顺序固定：

| 段号 | 内容 | 字数 | 必含要素 |
|------|------|------|----------|
| 第 1 段 | 背景 + 总方法 | 80-120 字 | 研究对象 + 核心难点 + 总体建模思路 |
| 第 2 段 | 问题一 | 100-150 字 | 方法名 + 模型类型 + 求解器/算法 + **核心数值结果** |
| 第 3 段 | 问题二 | 100-150 字 | 新增约束/因素 + 修正方法 + **核心数值结果** |
| 第 4 段 | 问题三 | 100-150 字 | 规模特征 + 框架（外层/内层）+ **核心数值结果** |
| 第 5 段 | 问题四 | 100-150 字 | 随机性/扩展性 + 处理方法 + **核心数值结果** |
| 第 6 段 | 总结 | 50-80 字 | 模型特色 + 推广价值 |

**总字数控制**：600-900 字，**不超过一页**。

### 三条硬性要求

1. **每段开头必须用"针对问题X"或"针对研究背景"领起**，结构清晰。
2. **第 2-5 段每段必须至少有一个加粗的具体数字结果**（用 `\res{}` 命令加粗）。
3. **方法名必须出现**（如 MILP、ARIMA、TOPSIS、K-means），不能只写"建立模型"。

## 二、黄金模板（拿来即填）

```
【第1段·背景】针对【研究背景】中【核心难点1】、【核心难点2】等问题，本文建立了以【核心模型】为核心、融合【辅助方法1】与【辅助方法2】的【模型框架类型】框架。

【第2段·Q1】针对问题一，【简述方法】，构建了以【目标】为目标的【模型类型】模型，包含【约束1】、【约束2】和【约束3】三类约束。调用【求解器】求解得到最优【指标】为【具体数字】。

【第3段·Q2】针对问题二，【新增约束/因素描述】，修正了【关键方程】。重新求解后，得到【指标】为【具体数字】，较问题一【上升/下降】【百分比】%。

【第4段·Q3】针对问题三，针对【规模特征】，设计了【双层/分层】框架：外层【方法】搜索【决策变量】，内层【方法】计算【目标】。求得【结果】为【具体数字】。

【第5段·Q4】针对问题四，引入【预测/分布模型】对【数据】拟合（μ=【均值】，σ=【标准差】），通过【N】次蒙特卡洛模拟验证，【指标】满足【约束】。

【第6段·总结】本文模型具有【普适性/扩展性】，对【实际场景】具有指导意义。
```

## 三、正反例对照

### 反例：空洞无物（直接出局）
> 本文针对 XX 问题进行了研究，建立了优化模型、预测模型和评价模型，使用了多种方法，得到了较好的结果，具有一定现实意义。

**问题**：无方法名、无数字、无结构、无信息量。

### 反例：只写方法无结果
> 针对问题一，本文建立了混合整数线性规划模型，考虑了库存平衡和产能约束，使用 Gurobi 求解。

**问题**：方法对了但**没有数字**，评卷人无法判断结果好坏。

### 正例：六段齐全 + 数字 + 方法名
> **针对**生产排程问题中**多级 BOM 耦合**、**产能瓶颈冲突**等复杂特征，本文建立了以混合整数线性规划（MILP）为核心、融合贪心算法与蒙特卡洛模拟的分层优化框架。
>
> **针对问题一**，构建了以总成本最小为目标的 MILP 模型，包含库存平衡、产能上限、生产逻辑三类约束。调用 Gurobi 求解得到最优总成本为 **152340 元**，其中库存费用 **42800 元**、准备费用 **109540 元**。
>
> **针对问题二**，引入子组件占用瓶颈设备的耦合约束，修正库存平衡方程。重新求解后最优总成本为 **168920 元**，较问题一上升 **10.9%**，额外成本主要来自设备切换。
>
> **针对问题三**，针对 52 周大规模维度，设计"外层遗传算法 + 内层 MILP"双层框架，将全年切分为 4 段独立求解。求得最优总成本为 **171250 元**，求解时间 **47 秒**。
>
> **针对问题四**，引入 ARIMA(1,1,1) 模型拟合需求分布（μ=320，σ=45），通过 10000 次蒙特卡洛模拟验证，当安全库存取 200 件时缺货率 **2.3%** < 5% 满足约束。
>
> 本文模型具有较强扩展性，可推广至多产品多车间排产场景。

## 四、六大题型的摘要侧重点

| 题型 | 第 2-5 段必报数字类型 | 方法名示例 |
|------|------------------------|------------|
| 优化类 | 目标函数值、下降百分比、求解时间 | MILP、动态规划、遗传算法 |
| 预测类 | R²、RMSE、MAPE、预测值 | ARIMA、LSTM、灰色预测 GM(1,1) |
| 评价类 | 综合得分、排名、权重 | TOPSIS、熵权法、AHP、模糊综合 |
| 分类类 | 聚类数、轮廓系数、分类准确率 | K-means、SVM、随机森林 |
| 统计类 | p 值、F 统计量、置信区间 | t 检验、ANOVA、卡方检验 |
| 机理类 | 平衡点、收敛值、稳态解 | ODE、差分方程、Runge-Kutta |

> 各题型完整范例见 `../02_优化类/摘要范例.md` 等各题型文件夹。

## 五、摘要写作流程（推荐 30 分钟内完成）

1. **5 分钟**：把全文 Q1-Q4 的核心数字抄到一个临时表（方法 / 指标 / 数值）。
2. **20 分钟**：按六段模板填空，每段先写方法再补数字。
3. **5 分钟**：检查三条硬性要求——段首"针对"、数字加粗、方法名出现。

> **绝对不要**在写正文之前写摘要。摘要必须最后写，是全文的"压缩快照"。

## 六、LaTeX 代码（六段式）

```latex
\abstractpage{基于【核心方法】与【辅助方法】的【研究对象】【问题类型】模型}%
{%
\textbf{针对【研究背景】中【核心难点1】、【核心难点2】等问题，本文建立了以【核心模型】为核心、融合【辅助方法1】与【辅助方法2】的【框架类型】框架。}

\textbf{针对问题一}，【方法】，构建了以【目标】为目标的【模型类型】模型，包含【约束1】、【约束2】和【约束3】三类约束。调用【求解器】求解得到最优【指标】为\res{【数字】}。

\textbf{针对问题二}，【新增约束】，修正了【关键方程】。重新求解后，得到【指标】为\res{【数字】}，较问题一\res{【上升/下降】}\res{【百分比】}\%。

\textbf{针对问题三}，针对【规模特征】，设计了\res{【双层】}框架：外层【方法】搜索【变量】，内层【方法】计算【目标】。求得\res{【结果】}为\res{【数字】}。

\textbf{针对问题四}，引入【预测模型】对【数据】拟合（$\mu=$【均值】，$\sigma=$【标准差】），通过【N】次蒙特卡洛模拟验证，\res{【指标】}满足【约束】。

\textbf{本文模型具有【普适性/扩展性】，对【实际场景】具有指导意义。}
}
```

**关键命令**：
- `\abstractpage{标题}{摘要正文}` — 自动居中标题、加粗"摘 要"、末尾关键词、单独成页。
- `\res{数字}` — 把数字加粗，方便评卷人快速定位结果。

## 七、关键词写法

5 个关键词，按"方法 → 对象 → 目标"顺序排列：

```
关键词：混合整数线性规划；遗传算法；蒙特卡洛模拟；生产排程；鲁棒优化
```

**反例**：`关键词：数学建模；优化；模型；求解；分析`（信息量为零）。

## 八、一句话总结

> **六段不空话，每段有方法有数字，加粗让评卷人 30 秒抓到亮点。**
