# 模型评价与推广

> 模型评价回答"模型好不好、能用到哪"。三段式：优点 / 缺点 / 推广。
> 本文件给出通用模板、六大题型侧重、避坑指南。

---

## 一、三段式结构

| 段 | 字数 | 核心内容 |
|---|------|----------|
| 模型优点 | 200-300 字 | 3-4 条，每条一句话 + 一句解释 |
| 模型不足 | 200-300 字 | 2-3 条，每条说"忽略什么 + 导致什么偏差" |
| 模型推广 | 200-300 字 | 2-3 条，每条说"可推广到 X 场景 / 用 Y 方法替代 Z" |

> **铁律**：模型评价字数 **600-900 字**。优点不能空夸，缺点不能敷衍，推广要具体。

---

## 二、模型优点写法

### 模板
```latex
\subsection{模型优点}

\begin{enumerate}
    \item \textbf{【优点关键词】}：【一句话概括】+【一句解释】。例：模型普适性强，可推广至【其他场景】；
    \item \textbf{【优点关键词】}：【一句话概括】+【一句解释】。例：算法高效，【方法】在【规模】下【秒级】求解；
    \item \textbf{【优点关键词】}：【一句话概括】+【一句解释】。例：约束全面，考虑了【约束1】、【约束2】等关键因素。
\end{enumerate}
```

### 六大题型优点关键词

| 题型 | 推荐优点关键词 |
|------|----------------|
| 优化类 | 求解高效 / 全局最优 / 约束全面 / 可扩展 |
| 预测类 | 拟合精度高 / 组合降方差 / 长期外推稳健 / 可解释 |
| 评价类 | 主客观结合 / 稳健性强 / 维度全面 / 可量化 |
| 分类类 | 准确率高 / 可解释 / 抗噪声 / 自动定类 |
| 统计类 | 前提检验严谨 / 非参数交叉 / 控制混淆 / 显著性强 |
| 机理类 | 物理意义明确 / 稳态可证 / 参数可辨识 / 数值稳定 |

### 正例（优化类）
```latex
\begin{enumerate}
    \item \textbf{求解高效}：MILP 模型在 1456 个决策变量规模下 8.3 秒求得全局最优解，满足实时排产需求；
    \item \textbf{约束全面}：考虑了库存平衡、产能上限、生产逻辑、BOM 耦合四类关键约束，贴近实际排产场景；
    \item \textbf{可扩展性强}：双层框架可平滑扩展至更大规模（52 周 → 365 天），仅需调整外层遗传算法参数；
    \item \textbf{鲁棒性好}：蒙特卡洛模拟证明方案在需求 ±20\% 扰动下缺货率仍 < 5\%。
\end{enumerate}
```

### 反例（空洞）
```latex
\begin{enumerate}
    \item 模型很好；
    \item 算法很快；
    \item 结果很准。
\end{enumerate}
```
**诊断**：无具体数字、无场景、无解释，纯凑字数。

## 三、模型不足写法

### 模板
```latex
\subsection{模型不足}

\begin{enumerate}
    \item \textbf{忽略了【因素】}：本文假设【简化】，实际中【真实情况】，可能导致【偏差方向】；
    \item \textbf{参数依赖【来源】}：【参数】来自【文献/假设】，实际场景需重新标定，否则【后果】；
    \item \textbf{【方法】局限}：【方法】在【场景】下【劣势】，可考虑【替代方法】改进。
\end{enumerate}
```

### 正例（预测类）
```latex
\begin{enumerate}
    \item \textbf{忽略结构性断点}：本文假设 GDP 序列无政策冲击，实际重大政策（如供给侧改革）会引入断点，可能导致预测偏乐观；
    \item \textbf{参数依赖历史}：ARIMA 系数基于 2000-2022 年数据估计，若未来经济结构变化，需重新标定；
    \item \textbf{长期外推局限}：ARIMA 超过 5 年的外推置信区间快速变宽（2030 年 CI 宽度达 9 万亿元），长期预测仅作参考。
\end{enumerate}
```

### 反例（敷衍）
```latex
\begin{enumerate}
    \item 模型还有改进空间；
    \item 部分假设可能不成立；
    \item 数据量不够大。
\end{enumerate}
```
**诊断**：无具体因素、无偏差方向、无改进方法。

## 四、模型推广写法

### 两个方向
1. **场景推广**：本模型可推广到哪些类似问题
2. **方法改进**：本模型可用什么方法进一步改进

### 模板
```latex
\subsection{模型推广}

\begin{enumerate}
    \item \textbf{场景推广}：本文【模型】框架可推广至【相似场景 1】、【相似场景 2】，仅需调整【参数/约束】；
    \item \textbf{方法改进}：可尝试用【方法 A】代替【方法 B】，以【改善方向】；
    \item \textbf{约束增强}：可引入【更复杂因素】，使模型更贴近实际。
\end{enumerate}
```

### 正例（评价类）
```latex
\begin{enumerate}
    \item \textbf{场景推广}：本文"熵权 + TOPSIS"框架可推广至供应链绩效评价、城市韧性评价、企业竞争力评价等多指标排序场景，仅需替换指标体系；
    \item \textbf{方法改进}：可尝试用 CRITIC 法代替熵权法做客观赋权，考虑指标变异性与冲突性；
    \item \textbf{约束增强}：可引入动态评价（时间维度），用面板 TOPSIS 追踪方案演化，使评价更贴近实际决策过程。
\end{enumerate}
```

### 反例（套话）
```latex
\begin{enumerate}
    \item 本模型可以应用到很多领域；
    \item 未来可以做更多研究。
\end{enumerate}
```
**诊断**：无具体场景、无替代方法、无改进方向。

## 五、六大题型完整评价范例

### 优化类完整范例
```latex
\section{模型评价与推广}

\subsection{模型优点}
\begin{enumerate}
    \item \textbf{求解高效}：MILP 在 1456 变量规模下 8.3 秒求全局最优，满足实时排产；
    \item \textbf{约束全面}：覆盖库存、产能、逻辑、BOM 四类约束，贴近实际；
    \item \textbf{可扩展}：双层框架可扩展至 365 天规模，仅调外层 GA 参数；
    \item \textbf{鲁棒}：需求 ±20\% 扰动下缺货率 < 5\%。
\end{enumerate}

\subsection{模型不足}
\begin{enumerate}
    \item \textbf{忽略切换时间}：假设瓶颈设备切换时间为 0，实际约 30 分钟/次，可能低估准备费用 5-8\%；
    \item \textbf{需求确定假设}：前 3 问假设需求已知，实际需预测，误差可能放大库存波动；
    \item \textbf{单目标}：仅优化成本，未考虑客户满意度、设备利用率等多目标。
\end{enumerate}

\subsection{模型推广}
\begin{enumerate}
    \item \textbf{场景推广}：可推广至多车间协同排产、冷链物流调度等 NP-hard 排程场景；
    \item \textbf{方法改进}：可用 Benders 分解代替双层 GA，提升大规模求解效率；
    \item \textbf{多目标扩展}：可引入 ε-约束法处理成本-满意度双目标，求 Pareto 前沿。
\end{enumerate}
```

## 六、避坑指南

### 坑 1：优点过多缺点过少
**对策**：优点 3-4 条，缺点 2-3 条，平衡可信。全是优点显得不客观。

### 坑 2：缺点不敢写真实问题
**对策**：写"忽略切换时间"比写"还有改进空间"更专业。评卷人欣赏自知之明。

### 坑 3：推广太虚
**对策**：必须说"推广到 X 场景，需调整 Y"，不能只说"可推广"。

### 坑 4：与正文矛盾
**对策**：优点不能与缺点矛盾（如优点说"考虑切换时间"，缺点说"忽略切换时间"）。

---

## 七、模型评价检查清单

- [ ] 优点 3-4 条，每条有数字/场景？
- [ ] 缺点 2-3 条，每条说"忽略什么 + 偏差方向"？
- [ ] 推广 2-3 条，每条说"推广到哪 + 怎么改"？
- [ ] 优点缺点不矛盾？
- [ ] 字数 600-900？

---

## 八、一句话总结

> **优点有数字，缺点有偏差方向，推广有具体场景与方法替代。不空夸不敷衍。**
