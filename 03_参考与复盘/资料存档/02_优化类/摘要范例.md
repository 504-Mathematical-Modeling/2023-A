## 一、优化类摘要的必报要素

| 要素 | 必须出现 | 示例 |
|------|----------|------|
| 模型类型 | 是 | MILP / LP / 动态规划 / 整数规划 |
| 目标函数 | 是 | 总成本最小 / 利润最大 / 距离最短 |
| 关键约束（≥3 类） | 是 | 库存平衡 / 产能上限 / 逻辑约束 |
| 求解器/算法 | 是 | Gurobi / CBC / 遗传算法 / 模拟退火 |
| 目标函数值 | 是 | **152340 元** |
| 对比基线的提升 | 强烈建议 | 较贪心算法下降 **12.3%** |
| 求解时间 | 大规模必报 | **47 秒** |

## 二、完整范例（生产排程类）

> **针对**多级 BOM 生产排程问题中**多级物料耦合**、**瓶颈设备产能冲突**、**随机需求波动**等复杂特征，本文建立了以混合整数线性规划（MILP）为核心、融合遗传算法与蒙特卡洛模拟的分层优化框架。
>
> **针对问题一**，构建了以总成本（库存费用 + 准备费用）最小为目标的 MILP 模型，包含库存平衡、产能上限、生产逻辑（大 M 法）三类约束。调用 Gurobi 11.0 求解得到最优总成本为 **152340 元**，其中库存费用 **42800 元**、准备费用 **109540 元**，较贪心算法下降 **12.3%**。
>
> **针对问题二**，引入子组件占用瓶颈设备的耦合约束，修正库存平衡方程。重新求解后最优总成本为 **168920 元**，较问题一上升 **10.9%**，额外成本主要来自设备切换增加 **5 次**。
>
> **针对问题三**，针对 52 周大规模维度（决策变量 1456 个），设计"外层遗传算法 + 内层 MILP"双层框架，将全年切分为 4 段独立求解。求得最优总成本为 **171250 元**，求解时间 **47 秒**，较单层 MILP 求解时间下降 **96.2%**。
>
> **针对问题四**，引入 ARIMA(1,1,1) 模型拟合需求分布（μ=320，σ=45），通过 10000 次蒙特卡洛模拟验证，当安全库存取 200 件时缺货率 **2.3%** < 5% 满足约束。
>
> 本文模型具有较强扩展性，可推广至多产品多车间排产场景。

**关键词**：混合整数线性规划；遗传算法；蒙特卡洛模拟；生产排程；鲁棒优化

## 三、完整范例（路径规划类）

> **针对**城市物流配送中**车辆容量约束**、**时间窗约束**、**多车协同**等复杂特征，本文建立了以带时间窗车辆路径问题（VRPTW）模型为核心、融合禁忌搜索与节约算法的混合求解框架。
>
> **针对问题一**，构建了以总配送距离最短为目标的 VRPTW 模型，包含车辆容量、时间窗、子回路消除三类约束。调用 Gurobi 求解得到最优总距离 **487.6 km**，使用车辆 **8 辆**。
>
> **针对问题二**，引入跨区域换乘约束，扩展为多车场 VRP。重新求解后最优总距离 **562.3 km**，较问题一增加 **15.3%**，使用车辆 **10 辆**。
>
> **针对问题三**，针对 200 客户点大规模场景，设计"节约算法构造初始解 + 禁忌搜索局部优化"的混合启发式框架。求得总距离 **612.8 km**，求解时间 **23 秒**，较精确算法在 1 小时内的可行解下降 **8.7%**。
>
> **针对问题四**，引入需求随机性（泊松分布 λ=4.2），通过 5000 次蒙特卡洛模拟验证，方案在 95% 置信下准时率 **93.1%** 满足 ≥90% 约束。
>
> 本文模型可推广至冷链配送、应急物资调度等场景。

**关键词**：车辆路径问题；禁忌搜索；节约算法；蒙特卡洛模拟；时间窗约束

## 四、反例与诊断

### 反例 1：方法名缺失
> 针对问题一，建立了优化模型，考虑了多种约束，得到了最优结果为 152340 元。

**诊断**：什么模型？什么求解器？什么约束？评卷人无从判断。

### 反例 2：约束数量不足
> 针对问题一，建立 MILP 模型，包含库存约束，求解得到 152340 元。

**诊断**：只说一类约束显得模型单薄。优化类摘要至少列 3 类约束。

### 反例 3：无对比基线
> 针对问题一，建立 MILP 模型，求解得到 152340 元。

**诊断**：152340 是好是坏？必须有对比（贪心算法 / 问题二 / 文献结果）。

### 反例 4：大规模问题不报求解时间
> 针对问题三，使用遗传算法求解，得到 171250 元。

**诊断**：大规模问题求解时间是评卷人判断算法实用性的关键。必须报。

## 五、优化类摘要填空模板

```latex
\textbf{针对问题一}，构建了以【目标函数】为目标的【MILP/LP/动态规划】模型，包含【约束1】、【约束2】和【约束3】三类约束。调用【Gurobi/CBC/自编算法】求解得到最优【指标】为\res{【数字】}【单位】，较【对比基线】【上升/下降】\res{【百分比】}\%。

\textbf{针对问题二}，引入【新增约束/因素】，修正【关键方程】。重新求解后最优【指标】为\res{【数字】}，较问题一\res{【上升/下降】}\res{【百分比】}\%，【原因解释】。

\textbf{针对问题三}，针对【规模特征：变量数/客户数/周期数】，设计"\res{【外层方法】}+\res{【内层方法】}"【双层/启发式】框架。求得最优【指标】为\res{【数字】}，求解时间\res{【数字】}秒，较【对比方法】下降\res{【百分比】}\%。

\textbf{针对问题四}，引入【随机性描述】，通过【N】次蒙特卡洛模拟验证，\res{【指标】}满足【约束】（置信水平【X】%）。
```

## 六、优化类摘要的数字精度规范

- **金额**：精确到元（如 152340 元），不用万元单位除非数字过大。
- **百分比**：保留 1 位小数（如 12.3%）。
- **求解时间**：精确到秒；超过 1 小时报"小时"。
- **变量数**：报告决策变量数和约束数（如"1456 个决策变量、3280 个约束"）。
- **不要堆数字**：每段最多 4 个数字，否则评卷人记不住。

## 七、一句话总结

> **优化类摘要 = 模型类型 + 目标 + 3 类约束 + 求解器 + 加粗结果 + 对比基线。**
