## 一、优化类建模三大决策

| 决策 | 选项 | 选择依据 |
|------|------|----------|
| 模型类型 | LP / MILP / NLP / 动态规划 | 是否含 0-1 决策、是否线性 |
| 求解方式 | 精确（Gurobi） / 启发式（GA/SA） | 规模大小、时间限制 |
| 多目标处理 | 加权和 / ε-约束 / Pareto | 目标是否冲突 |

## 二、MILP 模型标准模板

### 目标函数
```latex
\begin{equation}
    \min F = \underbrace{\sum_{i,t} H_i z_{i,t}}_{\text{库存费用}} + \underbrace{\sum_{i,t} S_i y_{i,t}}_{\text{准备费用}} + \underbrace{\sum_{i,t} P_i x_{i,t}}_{\text{生产费用}}
    \label{eq:opt-obj}
\end{equation}
```

### 常见约束类型

#### 1. 库存平衡约束（流量守恒）
```latex
\begin{equation}
    z_{i,t} = z_{i,t-1} + x_{i,t} - D_{i,t} - \sum_{j \in \mathcal{P}_i} R_{i,j} x_{j,t}, \quad \forall i, t
\end{equation}
```

#### 2. 产能约束（资源上限）
```latex
\begin{equation}
    \sum_{i \in \mathcal{B}_k} A_{i,k} x_{i,t} \leq C_{k,t}, \quad \forall k, t
\end{equation}
```

#### 3. 逻辑约束（大 M 法）
```latex
\begin{equation}
    x_{i,t} \leq M y_{i,t}, \quad x_{i,t} \geq 0, \quad y_{i,t} \in \{0,1\}
\end{equation}
```

#### 4. 互斥约束
```latex
\begin{equation}
    \sum_{i \in \mathcal{S}} y_{i,t} \leq 1, \quad \forall t
\end{equation}
```

#### 5. 最小批量约束
```latex
\begin{equation}
    x_{i,t} \geq L_i y_{i,t}, \quad \forall i, t
\end{equation}
```

#### 6. 时间窗约束（VRP 类）
```latex
\begin{equation}
    e_i \leq t_i \leq l_i, \quad \forall i
\end{equation}
```

## 三、求解器选择速查

| 求解器 | 适用模型 | 学术免费 | Python 接口 |
|--------|----------|----------|-------------|
| Gurobi | MILP / QP / QCQP | 是（注册学术账号） | `gurobipy` |
| CBC | MILP | 是（开源） | `pulp` |
| SCIP | MINLP | 是（开源） | `pyscipopt` |
| GLPK | LP / MILP | 是（开源） | `pulp` |
| OR-Tools | 约束规划 / VRP | 是（Google） | `ortools` |

### Python 调用示例（PuLP + CBC）
```python
import pulp

# 1. 创建问题
model = pulp.LpProblem("Production_Scheduling", pulp.LpMinimize)

# 2. 决策变量
x = pulp.LpVariable.dicts("x", (items, weeks), lowBound=0, cat='Integer')
y = pulp.LpVariable.dicts("y", (items, weeks), cat='Binary')
z = pulp.LpVariable.dicts("z", (items, weeks), lowBound=0)

# 3. 目标函数
model += pulp.lpSum(H[i]*z[i][t] + S[i]*y[i][t] for i in items for t in weeks)

# 4. 约束
for i in items:
    for t in weeks:
        # 库存平衡
        prev_z = z[i][t-1] if t > 0 else 0
        model += z[i][t] == prev_z + x[i][t] - D[i][t]
        # 大 M 法
        model += x[i][t] <= M * y[i][t]

# 5. 求解
model.solve(pulp.PULP_CBC_CMD(msg=0, timeLimit=120))
print(f"Status: {pulp.LpStatus[model.status]}")
print(f"Optimal Cost: {pulp.value(model.objective)}")
```

## 四、启发式算法设计要点

### 何时用启发式
- 决策变量数 > 10000
- 求解器 1 小时无解
- 强 NP-hard（VRP、TSP、调度）

### 遗传算法核心代码（Python）
```python
import numpy as np

def genetic_algorithm(pop_size=100, n_gen=200, p_c=0.8, p_m=0.05):
    # 1. 编码：整数序列
    pop = [np.random.permutation(n_items) for _ in range(pop_size)]
    best = None; best_fit = float('inf')
    
    for gen in range(n_gen):
        # 2. 适应度（调用 MILP 内层求解）
        fits = [evaluate(ind) for ind in pop]
        idx = np.argmin(fits)
        if fits[idx] < best_fit:
            best_fit = fits[idx]; best = pop[idx]
        
        # 3. 选择（锦标赛）
        parents = [tournament(pop, fits, k=3) for _ in range(pop_size)]
        
        # 4. 交叉（单点）
        children = []
        for i in range(0, pop_size, 2):
            if np.random.rand() < p_c:
                c1, c2 = crossover(parents[i], parents[i+1])
                children.extend([c1, c2])
            else:
                children.extend([parents[i], parents[i+1]])
        
        # 5. 变异（交换）
        pop = [mutate(c, p_m) for c in children]
    
    return best, best_fit
```

### 启发式必报要素
| 要素 | 必报值 |
|------|--------|
| 种群规模 | 100 |
| 最大代数 | 200 |
| 交叉概率 | 0.8 |
| 变异概率 | 0.05 |
| 收敛代数 | 第 X 代收敛 |
| 求解时间 | X 秒 |
| 与精确解对比 | 误差 < Y% |

## 五、双层优化框架写法

### 框架结构
```latex
\subsubsection{双层嵌套框架}

针对本问题【大规模特征】，设计"外层【遗传算法】+内层【MILP】"的双层嵌套框架：
\begin{itemize}
    \item \textbf{外层}：遗传算法在【决策变量空间】全局搜索【分段策略/排序】；
    \item \textbf{内层}：将【总周期】按【外层给定切分点】切分为【K】段，每段独立求 MILP；
    \item \textbf{衔接}：前一段期末库存 = 后一段期初库存。
\end{itemize}
```

## 六、多目标优化处理

### 加权和法（最简单）
```latex
\begin{equation}
    \min F = \alpha \frac{F_1}{F_1^*} + (1-\alpha) \frac{F_2}{F_2^*}
\end{equation}
其中 $F_1^*, F_2^*$ 为单目标最优值（归一化用），$\alpha$ 为权重，本文取 $\alpha=0.6$（依据【文献/灵敏度】）。
```

### ε-约束法
```latex
将次要目标 $F_2$ 转为约束：$\min F_1$，s.t. $F_2 \leq \epsilon$。通过扫描 $\epsilon$ 获得 Pareto 前沿。
```

## 八、避坑指南

### 坑 1：约束矛盾无解
**对策**：先放松约束（大 M 调小、产能放宽），若仍无解则用 `pulp.LpStatus` 检查，定位冲突约束。

### 坑 2：求解超时
**对策**：1) 减小决策变量数（聚合时间维度）；2) 加 valid inequality；3) 改启发式。

### 坑 3：结果不可复现
**对策**：固定随机种子 `np.random.seed(42)`，报告求解器版本与参数。

### 坑 4：单位混乱
**对策**：所有变量统一单位（如全用"件"和"元"），符号表核对。
