# 评价类摘要范例

> 评价类题目（AHP / TOPSIS / 熵权 / 模糊综合 / 灰色关联）的摘要专用范例。
> 通用规范见 `../01_通用写作规范/摘要六段法通用规范.md`。

---

## 一、评价类摘要的必报要素

| 要素 | 必须出现 | 示例 |
|------|----------|------|
| 评价方法 | 是 | AHP / TOPSIS / 熵权法 / 模糊综合 |
| 权重确定方式 | 是 | 主观（AHP）/ 客观（熵权）/ 组合赋权 |
| 评价指标数 | 是 | 12 个指标 4 个维度 |
| 一致性检验 | AHP 必报 | CR=0.05 < 0.1 |
| 综合得分与排名 | 是 | 方案 A 得分 0.873 排名第 1 |
| 灵敏度验证 | 强烈建议 | 权重 ±20% 排序不变 |

## 二、完整范例（方案评价）

> **针对**城市交通系统综合评价中**指标量纲不一**、**主观客观权重冲突**、**评价结果稳健性存疑**等复杂特征，本文建立了以熵权 TOPSIS 为核心、融合 AHP 主观赋权与灰色关联的混合评价框架。
>
> **针对问题一**，从经济性、便捷性、安全性、环保性 4 个维度构建 12 项指标体系，采用熵权法确定客观权重（最高权重指标"人均通勤时间"= **0.143**），用 TOPSIS 计算各方案贴近度。结果显示方案 A 贴近度 **0.873** 排名第 1，方案 C 贴近度 **0.412** 排名末位。
>
> **针对问题二**，引入 AHP 主观权重（CR=**0.05** < 0.1 通过一致性检验），与熵权法按 0.5:0.5 组合赋权。重新评价后方案 A 仍居第 1，贴近度上修为 **0.891**，方案 B 与方案 C 位次互换，说明主观偏好对中段排序敏感。
>
> **针对问题三**，针对"贴近度差异小导致排序不稳"的争议，引入灰色关联度做交叉验证。组合"TOPSIS 贴近度 + 灰色关联度"双指标排名，方案 A 综合得分 **0.852** 稳居第 1，验证了排序稳健性。
>
> **针对问题四**，对组合权重做 ±20% 灵敏度分析，通过 1000 次蒙特卡洛模拟，方案 A 排名第 1 的概率 **97.3%**，方案 C 排名末位的概率 **89.5%**，证明评价结果在权重扰动下稳健。
>
> 本文混合评价框架可推广至供应链绩效、城市韧性、企业竞争力等评价场景。

**关键词**：熵权法；TOPSIS；层次分析法；灰色关联；灵敏度分析

## 三、完整范例（模糊综合评价）

> **针对**高校教学质量评价中**指标模糊性**、**评价主体多元**、**等级边界不清**等复杂特征，本文建立了以模糊综合评价为核心、融合熵权法与 CIS 优化的混合评价框架。
>
> **针对问题一**，从教学内容、教学方法、教学效果 3 个维度构建 10 项指标，采用熵权法确定权重（最大权重"课堂参与度"= **0.156**），建立评语集 V={优,良,中,差}，模糊综合评价得到教师 X 综合得分 **84.6** 分，等级"良"。
>
> **针对问题二**，引入学生、同行、督导 3 类评价主体，构建多层模糊综合评价。重新评价后教师 X 综合得分 **86.2** 分，其中学生评价 **88.1**、同行评价 **82.5**、督导评价 **86.4**，等级上修为"良+"。
>
> **针对问题三**，针对模糊算子选择争议，对比"主因素决定型 M(∧,∨)"与"加权平均型 M(·,+)"两种算子。加权平均型更保留全部信息，教师 X 得分 **87.3**，较主因素型 **82.1** 提升 **6.3%**，采用加权平均型作为最终结果。
>
> **针对问题四**，对隶属度函数做 ±10% 扰动，通过 5000 次蒙特卡洛模拟，教师 X 等级"良+"的概率 **92.4%**，验证了评价稳健性。
>
> 本文模糊评价框架可推广至服务满意度、产品体验、政策效果等模糊场景。

**关键词**：模糊综合评价；熵权法；隶属度函数；多主体评价；蒙特卡洛模拟

## 四、反例与诊断

### 反例 1：不报一致性检验
> 针对问题一，用 AHP 确定权重，方案 A 得分 0.873。

**诊断**：AHP 不报 CR 就等于没做。必须报 CR=具体值 < 0.1。

### 反例 2：指标数模糊
> 针对问题一，从多维度建立指标体系，方案 A 排名第 1。

**诊断**：几个维度？几项指标？必须报具体数字（如"4 个维度 12 项指标"）。

### 反例 3：无灵敏度分析
> 针对问题一，TOPSIS 评价方案 A 第 1。

**诊断**：评价类题目最大争议是权重主观性。必须有灵敏度分析证明排序稳健。

### 反例 4：得分无对比基线
> 方案 A 贴近度 0.873。

**诊断**：0.873 是高是低？必须报第 2 名、末位贴近度形成对比。

## 六、评价类摘要的数字规范

| 数字类型 | 报告精度 | 备注 |
|----------|----------|------|
| 权重 | 3 位小数 | 必报最大权重对应指标 |
| 贴近度 | 3 位小数 | TOPSIS 必报 |
| 综合得分 | 1 位小数 | 与评价尺度一致 |
| CR 一致性比率 | 2 位小数 | AHP 必报，须 < 0.1 |
| 灵敏度概率 | 1 位小数（%） | 蒙特卡洛必报 |

---

## 七、一句话总结

> **评价类摘要 = 指标体系（N 维 M 项）+ 权重方法 + 一致性检验 + 排名 + 灵敏度验证。**
