## 一、评价类建模五步流程

```
1. 构建指标体系（维度→指标）
2. 数据规范化（消除量纲）
3. 确定权重（主观/客观/组合）
4. 综合评价（TOPSIS/模糊/灰色）
5. 稳健性验证（灵敏度 + 交叉验证）
```

## 二、指标体系构建规范

### 维度与指标数规范
| 推荐维度数 | 推荐指标数 | 备注 |
|------------|------------|------|
| 3-5 个维度 | 每维度 2-4 个指标 | 总指标 8-15 个 |

### 指标选取三原则
1. **可测性**：每个指标可量化或可定性打分
2. **独立性**：指标间相关系数 |r| < 0.8（避免共线）
3. **完备性**：覆盖研究对象主要方面

### 指标规范化公式

#### 极大型（越大越好）
```latex
\begin{equation}
    r_{ij} = \frac{x_{ij} - \min_i x_{ij}}{\max_i x_{ij} - \min_i x_{ij}}
\end{equation}
```

#### 极小型（越小越好）
```latex
\begin{equation}
    r_{ij} = \frac{\max_i x_{ij} - x_{ij}}{\max_i x_{ij} - \min_i x_{ij}}
\end{equation}
```

#### 区间型（适中最好）
```latex
\begin{equation}
    r_{ij} = \begin{cases}
        1 - \frac{[a - x_{ij}]}{\max(a-\min, \max-b)}, & x_{ij} < a \\
        1, & a \leq x_{ij} \leq b \\
        1 - \frac{[x_{ij} - b]}{\max(a-\min, \max-b)}, & x_{ij} > b
    \end{cases}
\end{equation}
```

## 三、权重确定三大方法

### 方法 1：AHP 主观赋权

#### 判断矩阵构建
```latex
\subsubsection{AHP 主观赋权}

邀请【3 位专家】对 4 个维度两两比较，构建判断矩阵 $\mathbf{A}=(a_{ij})_{4\times 4}$，其中 $a_{ij}$ 取 1-9 标度：
\begin{equation}
    \mathbf{A} = \begin{pmatrix}
        1 & 3 & 5 & 2 \\
        1/3 & 1 & 2 & 1 \\
        1/5 & 1/2 & 1 & 1/2 \\
        1/2 & 1 & 2 & 1
    \end{pmatrix}
\end{equation}
```

#### 权重计算与一致性检验
```latex
用特征值法求最大特征值 $\lambda_{\max}=4.021$，对应特征向量归一化得权重：
\begin{equation}
    \mathbf{w} = (0.483, 0.157, 0.088, 0.272)^T
\end{equation}
一致性指标 $CI = \frac{\lambda_{\max}-n}{n-1} = 0.007$，随机一致性 $RI=0.89$，一致性比率 $CR = CI/RI = 0.008 < 0.1$，通过一致性检验。
```

### 方法 2：熵权法客观赋权

```latex
\subsubsection{熵权法客观赋权}

第 $j$ 指标的信息熵：
\begin{equation}
    E_j = -\frac{1}{\ln n} \sum_{i=1}^{n} p_{ij} \ln p_{ij}, \quad p_{ij} = \frac{r_{ij}}{\sum_i r_{ij}}
\end{equation}
权重：
\begin{equation}
    w_j = \frac{1 - E_j}{\sum_k (1 - E_k)}
\end{equation}
计算结果：经济性 $w_1=0.312$、便捷性 $w_2=0.245$、安全性 $w_3=0.283$、环保性 $w_4=0.160$。
```

### 方法 3：组合赋权

```latex
\subsubsection{组合赋权}

采用线性组合：$w_j = \alpha w_j^{(AHP)} + (1-\alpha) w_j^{(EW)}$，本文取 $\alpha=0.5$（主观客观并重）。组合权重见表\ref{tab:weights}。
```

### Python 实现（熵权 + TOPSIS）
```python
import numpy as np

def entropy_weight(X):
    """X: 规范化矩阵 n×m"""
    P = X / X.sum(axis=0)
    E = -np.sum(P * np.log(P + 1e-12), axis=0) / np.log(len(X))
    w = (1 - E) / (1 - E).sum()
    return w

def topsis(X, w):
    """X: 规范化矩阵, w: 权重"""
    V = X * w
    v_plus = V.max(axis=0)
    v_minus = V.min(axis=0)
    d_plus = np.sqrt(((V - v_plus)**2).sum(axis=1))
    d_minus = np.sqrt(((V - v_minus)**2).sum(axis=1))
    C = d_minus / (d_plus + d_minus)
    return C

# 调用
X = np.array([[0.8, 0.6, 0.9, 0.7],
              [0.6, 0.9, 0.7, 0.8],
              [0.4, 0.5, 0.6, 0.4]])
w = entropy_weight(X)
C = topsis(X, w)
print(f"权重: {w}")
print(f"贴近度: {C}")
print(f"排名: {np.argsort(-C)+1}")
```

## 四、TOPSIS 综合评价

### 完整流程写法
```latex
\subsubsection{TOPSIS 综合评价}

\textbf{（1）规范化加权矩阵：}
\begin{equation}
    v_{ij} = w_j \cdot r_{ij}
\end{equation}

\textbf{（2）正负理想解：}
\begin{equation}
    v_j^+ = \max_i v_{ij}, \quad v_j^- = \min_i v_{ij}
\end{equation}

\textbf{（3）欧氏距离：}
\begin{equation}
    d_i^+ = \sqrt{\sum_j (v_{ij} - v_j^+)^2}, \quad d_i^- = \sqrt{\sum_j (v_{ij} - v_j^-)^2}
\end{equation}

\textbf{（4）贴近度：}
\begin{equation}
    C_i = \frac{d_i^-}{d_i^+ + d_i^-}, \quad C_i \in [0,1]
\end{equation}
$C_i$ 越大方案越优。计算结果见表\ref{tab:topsis}。
```

## 五、模糊综合评价

### 隶属度函数（三角型）
```latex
\subsubsection{隶属度函数}

对评语集 $V=\{优, 良, 中, 差\}$，采用三角隶属度函数：
\begin{equation}
    \mu_v(x) = \begin{cases}
        \frac{x-a}{b-a}, & a \leq x \leq b \\
        \frac{c-x}{c-b}, & b \leq x \leq c \\
        0, & \text{其他}
    \end{cases}
\end{equation}
```

### 模糊合成
```latex
\textbf{模糊合成}：$\mathbf{B} = \mathbf{w} \circ \mathbf{R}$，其中 $\mathbf{R}$ 为隶属度矩阵，$\circ$ 为加权平均算子 $M(\cdot, +)$。教师 X 的综合评价：
\begin{equation}
    \mathbf{B} = (0.35, 0.42, 0.18, 0.05)
\end{equation}
按最大隶属度原则，等级为"良"。综合得分 $= 0.35\times 95 + 0.42\times 85 + 0.18\times 75 + 0.05\times 65 = \res{86.2}$。
```

## 六、稳健性验证（必做）

### 灵敏度分析
```latex
\subsubsection{权重灵敏度分析}

对组合权重 $w_j$ 做 $\pm 20\%$ 扰动，重新计算 TOPSIS 排序。结果：方案 A 在 5/5 种扰动下均排第 1，方案 C 均排末位，证明排序稳健。
```

### 蒙特卡洛交叉验证
```latex
\subsubsection{蒙特卡洛稳健性}

对权重做 1000 次随机扰动（每次从 Dirichlet 分布抽样），统计各方案排名第 1 的频率：方案 A \res{97.3\%}、方案 D \res{2.1\%}、方案 B \res{0.6\%}，证明方案 A 稳健最优。
```

## 七、避坑指南

### 坑 1：AHP 不报 CR
**对策**：必须报 CR 值，且 CR < 0.1。

### 坑 2：指标共线性
**对策**：计算指标间相关系数矩阵，剔除 |r| > 0.8 的冗余指标。

### 坑 3：规范化方向错
**对策**：极大型用 max-min，极小型用 min-max，方向反了评价全错。

### 坑 4：无稳健性验证
**对策**：评价类最大争议是权重主观性，必须有灵敏度 + 蒙特卡洛。

### 坑 5：模糊算子选错
**对策**：主因素型 $M(\wedge, \vee)$ 信息损失大，推荐加权平均型 $M(\cdot, +)$。
