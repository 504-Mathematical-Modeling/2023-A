## 项目背景

数学建模竞赛的论文写作是获奖的关键环节，但许多参赛者把精力全部放在建模上，忽视了论文的结构、规范与表达。本模板体系基于多届数学建模竞赛（高教社杯 / 华数杯 / MathorCup 等）获奖团队的实战经验沉淀，整合官方 LaTeX 模板、2026 国赛 AI 使用试行规范、可复用提示词等一手资料，为参赛者提供一套"开箱即用"的论文写作解决方案。

**核心理念**：写论文不是最后一步，而是贯穿建模始终的主线。

---

## 核心特性

- **LaTeX 骨架模板**：基于 `ctexart` 文档类，`fontset=fandol` 跨平台无字体依赖，支持 xelatex 一键编译
- **六大题型全覆盖**：优化 / 预测 / 评价 / 分类 / 统计 / 机理，每类配套问题分析、摘要范例、建模要点、专用话术
- **摘要六段法**：背景+总方法 / Q1 / Q2 / Q3 / Q4 / 总结，每段必含具体数值结果
- **通用四小节结构**：问题分析 → 模型建立 → 模型求解 → 结果分析，适配绝大多数赛题
- **2026 国赛新规适配**：AI 使用声明置于参考文献之前，符合最新规范
- **排版红线**：图题在下、表题在上；表格一律三线表（无竖线）；首行缩进2字符
- **AI 协作 Prompt 库**：可直接复用的提示词模板，规范 AI 辅助写作流程
- **提交前检查清单**：30+ 项检查点，确保提交前零低级错误

## 快速开始

### 环境要求

- **TeX 发行版**：TeX Live 2024+（推荐）/ MiKTeX / Tectonic
- **编辑器**：VS Code（配合 LaTeX Workshop 扩展）/ TeXstudio / WinEdt
- **编译器**：XeLaTeX（模板默认，中文支持最佳）

### 三步上手

**1. 克隆仓库**

```bash
git clone https://github.com/xinhezhix-ctrl/math-modeling-paper-template-in-2026.git
cd math-modeling-paper-template-in-2026
```

**2. 编译模板**

```bash
cd 数学建模论文撰写专用模板/00_LaTeX基础模板与排版
xelatex 数学建模论文通用LaTeX模板.tex
```

或者使用 latexmk（推荐，自动处理多遍编译）：

```bash
latexmk -xelatex 数学建模论文通用LaTeX模板.tex
```

**3. 开始写作**

- 全局搜索 `【替换】` 字样，按提示替换为你的内容
- 按 `数学建模论文撰写专用模板/01_通用写作规范/` 中的章节顺序组织论文
- 根据题型参考 `数学建模论文撰写专用模板/02_优化类/` ~ `07_机理建模类/` 对应文件夹

## 使用指南

### 论文骨架与章节顺序

完整论文应包含以下章节（顺序不可调整）：

1. **摘要**（六段法，一页以内）
2. **关键词**（3-5个，分号分隔）
3. **问题重述**（背景+问题归纳，2页以内）
4. **问题分析**（每个子问题1段，含思路与方法选择）
5. **模型假设**（编号列出，每条说明假设理由）
6. **符号说明**（三线表，符号+含义+单位）
7. **模型建立与求解**（按子问题组织，每个含四小节）
   - 7.1 问题一的四小节
   - 7.2 问题二的四小节
   - ...
8. **模型检验与敏感性分析**（鲁棒性验证）
9. **模型评价与推广**（优点/缺点/推广方向）
10. **AI 使用声明**（2026国赛新规，参考文献前）
11. **参考文献**（GB/T 7714 格式）
12. **附录**（代码+完整结果表）

### 摘要六段法

| 段落 | 内容 | 关键要求 |
|------|------|---------|
| 第1段 | 背景+总体方法 | 2-3句背景，1句总方法 |
| 第2段 | 问题一方法+结果 | 必须含具体数值结果 |
| 第3段 | 问题二方法+结果 | 必须含具体数值结果 |
| 第4段 | 问题三方法+结果 | 必须含具体数值结果 |
| 第5段 | 问题四方法+结果 | 必须含具体数值结果 |
| 第6段 | 总结+模型特色 | 1句总结，1-2句特色 |

**铁律**：摘要中不出现公式、不出现图表、每段必须有具体数值结果。

### 通用四小节结构

每个子问题的建模部分按以下四小节组织：

1. **问题分析**：本问要解决什么？为什么选这个方法？
2. **模型建立**：数学表达（公式+文字说明）
3. **模型求解**：算法+参数+实现
4. **结果分析**：数值结果+图表+结论

## LaTeX 编译配置

### VS Code 配置（推荐）

1. 安装 **LaTeX Workshop** 扩展
2. 在 `settings.json` 中添加：

```json
{
    "latex-workshop.latex.tools": [
        {
            "name": "xelatex",
            "command": "xelatex",
            "args": [
                "-synctex=1",
                "-interaction=nonstopmode",
                "-file-line-error",
                "%DOC%"
            ]
        },
        {
            "name": "latexmk",
            "command": "latexmk",
            "args": [
                "-xelatex",
                "-synctex=1",
                "-interaction=nonstopmode",
                "-file-line-error",
                "%DOC%"
            ]
        }
    ],
    "latex-workshop.latex.recipes": [
        {
            "name": "latexmk (xelatex)",
            "tools": ["latexmk"]
        },
        {
            "name": "xelatex",
            "tools": ["xelatex"]
        }
    ],
    "latex-workshop.view.pdf.viewer": "tab"
}
```

### TeXstudio 配置

1. 选项 → 配置 → 构建
2. 默认编译器：XeLaTeX
3. 默认 bibliography：BibTeX

## 2026 国赛新规：AI 使用声明

2026 年国赛试行 AI 使用规范，论文须在参考文献之前加入"AI 使用声明"章节，说明：

1. **使用的 AI 工具**：名称+版本（如 ChatGPT-4 / Claude 3.5）
2. **使用环节**：文献检索 / 代码生成 / 语言润色 / 思路启发
3. **使用比例**：AI 生成内容占全文的比例估算
4. **人工把关**：团队如何验证 AI 生成内容的准确性

详细规范见 [`数学建模论文撰写专用模板/00_LaTeX基础模板与排版/AI使用规范.txt`](数学建模论文撰写专用模板/00_LaTeX基础模板与排版/AI使用规范.txt)。
