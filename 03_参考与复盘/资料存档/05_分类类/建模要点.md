```
目标？
├── 无标签 → 聚类（无监督）
│   ├── 凸形簇 + 已知 K → K-means

    ├── 高维 + 可解释 → 决策树 / 随机森林
    └── 非线性 → XGBoost / 神经网络
```

## 三、K-means 聚类

### 类别数 K 的确定（必报）
```latex
\subsubsection{最优 K 值确定}

\textbf{（1）肘部法}：绘制 $K \in [2,10]$ 的 SSE 曲线，发现 $K=5$ 处出现明显拐点（见图\ref{fig:elbow}）。

\textbf{（2）轮廓系数}：计算各 $K$ 的平均轮廓系数，$K=5$ 时取得最大值\res{0.62}：
\begin{equation}
    s(i) = \frac{b(i) - a(i)}{\max\{a(i), b(i)\}}, \quad s \in [-1, 1]
\end{equation}
其中 $a(i)$ 为样本 $i$ 到同簇其他样本的平均距离，$b(i)$ 为到最近其他簇的平均距离。

\textbf{（3）Calinski-Harabasz 指数}：$K=5$ 时 CH=\res{823.4}（越大越好）。

三种方法共同确定 $K^*=5$。
```

### Python 实现
```python
from sklearn.cluster import KMeans
from sklearn.metrics import silhouette_score, calinski_harabasz_score

# 试 K 值
for k in range(2, 11):
    km = KMeans(n_clusters=k, random_state=42, n_init=10).fit(X)
    s = silhouette_score(X, km.labels_)
    ch = calinski_harabasz_score(X, km.labels_)
    print(f"K={k}: silhouette={s:.3f}, CH={ch:.1f}")

# 最终聚类
km = KMeans(n_clusters=5, random_state=42, n_init=10).fit(X)
labels = km.labels_
centers = km.cluster_centers_
```

### 随机森林判别
```latex
\subsubsection{随机森林判别}

针对新客户无历史行为无法聚类的难题，构建"K-means 训练 + 随机森林判别"两阶段框架。随机森林参数：$n_{estimators}=200$，$max\_depth=10$。

5 折交叉验证准确率\res{89.2\%}，对 200 名新客户分类，高价值客户识别准确率\res{93.1\%}。

特征重要度前 3：RFM 中"最近购买天数"\res{0.213}、"累计消费"\res{0.187}、"购买频次"\res{0.156}。
```

### Python 实现
```python
from sklearn.ensemble import RandomForestClassifier

rf = RandomForestClassifier(n_estimators=200, max_depth=10, random_state=42)
scores = cross_val_score(rf, X_train, y_train, cv=5, scoring='accuracy')

rf.fit(X_train, y_train)
importances = rf.feature_importances_
```

## 八、有效性验证（必做）

### 内部指标（无标签）
| 指标 | 含义 | 推荐值 |
|------|------|--------|
| 轮廓系数 | 簇内紧 vs 簇间分 | > 0.5 |
| Calinski-Harabasz | 类间方差/类内方差 | 越大越好 |
| Davies-Bouldin | 类内距/类间距 | < 0.5 |

### 外部指标（有标签）
| 指标 | 含义 | 推荐值 |
|------|------|--------|
| 准确率 | 分类正确率 | > 0.85 |
| F1-score | 精确率与召回率调和 | > 0.80 |
| AUC | ROC 曲线下面积 | > 0.85 |

### 交叉验证（必做）
```latex
\subsubsection{5 折交叉验证}

5 折交叉验证：准确率 \res{89.2±2.1\%}，F1-score \res{0.873}，AUC \res{0.94}，证明模型泛化能力良好。
```

## 九、避坑指南

### 坑 1：K 凭感觉
**对策**：肘部法 + 轮廓系数 + CH 指数三方法共同确定。

### 坑 2：K-means 不标准化
**对策**：K-means 用欧氏距离，必须先 `StandardScaler` 标准化，否则大量纲特征主导。

### 坑 3：无交叉验证
**对策**：判别分析必报 5 折或 10 折 CV，否则过拟合嫌疑。

### 坑 4：类别不均衡未处理
**对策**：用 `class_weight='balanced'` 或 SMOTE 过采样。

### 坑 5：随机种子不固定
**对策**：`random_state=42`，结果可复现。
